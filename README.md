폭스러닝센터 AI 연구소 | 담당 박성주

> 1탄에서 에이전트는 언제나 네 옆에 있었다.
> 지하는 네가 갈 수 없는 곳이다. 옆이 아니라 **좌표로** 보내야 한다.

「에이전트와 함께해요」의 다음 이야기다. **1탄 수료생을 대상으로 하고, 1탄에서 배운 것은 다시 가르치지 않는다.**

## 아이용 웹 교재

**https://sungjjoo.github.io/fox-signal-12/**

층을 고르면 그 차시의 신호·임무·코드·계산 기록·확장 과제가 나온다. 수업 중 QR로 접속한다.

**기록은 이름별로 분리 저장된다.** 첫 접속 때 이름을 넣으면 그 이름 칸에 쌓인다. 같은 노트북을 다른 친구가 써도 섞이지 않는다.
`sheet/README.md` 대로 구글 시트를 연결하면 노트북이 바뀌어도 이름만 넣으면 지난 기록이 따라오고, **연구원은 시트 하나로 전체 아이의 진도를 본다.** 연결하지 않아도 수업은 그대로 돌아간다.

## 1탄과 무엇이 다른가

| | 1탄 | 2탄 |
|---|---|---|
| 숫자 바꾸기 | 코드 열고 → 고치고 → 저장 | 채팅에 `dive 5` |
| 에이전트 위치 | 항상 내 옆 (`teleportToPlayer`) | 좌표로 어디든 (`world`) |
| 반복의 `i` | 횟수 세기만 | 좌표 계산의 재료 |
| 결과 | 만들어지는 것 | 만들어지고 **숫자로 보고된다** |
| 명령 | 하나의 동작 | 입력에 따라 여러 형태로 동작 |

## 처음 준비하는 순서

1. `context-notes.md` 를 먼저 읽는다. 전제와 좌표 규칙이 전부 여기 있다.
2. `world/README.md` 대로 월드를 만들고 `world/build.js` 를 실행한다.
3. `code/all-floors.js` 를 MakeCode JS 탭에 붙여넣어 **블록으로 전부 변환되는지** 확인한다.
4. `checklist.md` 의 "첫 수업 전 반드시 확인할 것" 을 실기로 통과시킨다.
5. `operations/rehearsal.md` 로 시연 동선을 한 번 돌린다.

## 코드 규칙

MakeCode JS 탭에 붙여넣어 **블록 코딩으로 변환해서** 아이에게 보여주는 것이 전제다.
그래서 static TypeScript 서브셋만 쓴다. 자세한 목록은 `code/README.md`.

- 쓴다 — `let` · `for` · `if/else` · `player.onChat` · 사칙연산 · 비교 · `변수 = 변수 + 1`
- 안 쓴다 — 화살표 함수 · 객체·배열 · `while(true)` · `const` · 템플릿 리터럴 · 사용자 정의 `function` · `!`
- 채팅 매개변수는 MakeCode가 만드는 이름 그대로 `num1` `num2` `num3`
- 방향 상수는 축약형 (`FORWARD` `DOWN` `RIGHT_TURN` `WEST`)

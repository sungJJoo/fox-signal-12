# 지하 12층 — 신호를 따라서

**Minecraft Education 기반 초등 고학년 코딩 프로그램 · 12차시 × 90분**
폭스러닝센터 AI 연구소 | 담당 박성주

> 지하에서 신호가 올라온다. 신호는 숫자 세 개만 반복한다.
> 사람은 내려갈 수 없다. 내려갈 수 있는 건 에이전트뿐이다.
> 너는 지상 관제실의 오퍼레이터다.

「에이전트와 함께해요」의 다음 버전이다. **좌표**와 **변수**를 축으로 확장성을 열고, 아이가 직접 보는 웹 교재를 붙였다.

```

└── operations/           ← 리허설 노트, 트러블슈팅
```

## 처음 준비하는 순서

1. `context-notes.md` 를 먼저 읽는다. 좌표 규칙이 전부 여기 있다.
2. `world/README.md` 대로 월드를 만들고 `world/build.js` 를 실행한다.
3. `code/all-floors.js` 를 MakeCode JS 탭에 붙여넣어 **블록으로 전부 변환되는지** 확인한다.
4. `checklist.md` 의 "첫 수업 전 반드시 확인할 것" 을 실기로 통과시킨다.
5. `operations/rehearsal.md` 로 시연 동선을 한 번 돌린다.

---

## 코드 규칙

MakeCode JS 탭에 붙여넣어 **블록 코딩으로 변환해서** 아이에게 보여주는 것이 전제다.
그래서 코드는 static TypeScript 서브셋만 쓴다. 자세한 목록은 `context-notes.md` 4장.

- 쓴다 — `let` · `for` · `if/else` · `player.onChat` · 사칙연산
- 안 쓴다 — 화살표 함수 · 객체·배열 리터럴 · `while(true)` · `const` · 템플릿 리터럴 · 사용자 정의 `function`
- 방향 상수는 축약형 (`FORWARD` `DOWN` `RIGHT_TURN` `WEST`) 으로 통일한다

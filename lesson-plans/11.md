## 오늘의 신호

> 신호가 갑자기 강해졌다. 12층이 코앞이다.
> 관제실은 마지막 점검을 지시한다.
>
> **1층부터 11층까지 전부 다시 훑고, 꺼진 유도등을 전부 다시 켤 것.**
>
> 층마다 명령을 만들면 스물두 개다. 지금까지 배운 걸 합치면 두 개면 된다.

---

## 목표

- **사고** 여러 차시에서 배운 요소를 하나의 명령 안에서 조합한다.
- **사고** 반복 안에 반복이 있고 그 안에서 계산과 누적이 동시에 일어나는 구조를 읽어낸다.
- **결과물** 구간 스캔 `scan` 과 층별 유도등 자동 설치 `relight` 를 완성한다.

## 흐름

### 도입 · 10분

지금까지 만든 명령 목록을 화면에 띄운다. 마흔 개가 넘는다.

> "이 중에 11층 유도등을 켜는 명령이 있어?"

없다. 6차시 `row` 는 6층 좌표가 박혀 있고, 9차시 `down` 은 이동만 한다.

> "그럼 새로 만들어야 해? 아니야. **합치면 돼.**"

칠판에 네 줄을 쓴다.

```
매개변수     어느 층부터 어디까지인지 채팅으로     2·3차시
계산         층 번호로 Y를 만든다                5차시
반복 변수    i 로 유도등 자리를 만든다            6차시
누적         층 번호를 1씩 키운다                9차시
```

### 전개 · 55분

**① `scan` (15분)**

9차시 `down` 과 거의 같다. 먼저 몸을 풀고 간다.

```ts
let checkFloor = 1

player.onChat("scan", function (num1, num2) {
    checkFloor = num1
    if (checkFloor < 1) { checkFloor = 1 }
    let last = num2
    if (last < checkFloor) { last = checkFloor }
    for (let i = 0; i < last - checkFloor + 1; i++) {
        let y = 62 - checkFloor * 4
        agent.teleport(world(-12, y, 8), WEST)
        loops.pause(600)
        player.say(y)
        checkFloor = checkFloor + 1
    }
    player.say("전층 스캔 완료")
})
```

`scan 1 11` → 58부터 18까지 열한 개 숫자가 차례로 찍힌다.

**② `light` — 층을 매개변수로 (15분)**

6차시 `row` 에서 층 좌표가 박혀 있던 걸 매개변수로 뺀다.

```ts
player.onChat("light", function (num1, num2, num3) {
    let y = 62 - num1 * 4
    let count = num2
    let gap = num3
    ...
    for (let i = 0; i < count; i++) {
        agent.teleport(world(-12 - i * gap, y, 8), WEST)
        ...
        lampTotal = lampTotal + 1
    }
    player.say("설치 누적")
    player.say(lampTotal)
})
```

`light 11 6 3` → 11층에 여섯 개를 3칸 간격으로.
`light 7 4 5` → 7층에 네 개를 5칸 간격으로.

**한 명령으로 열두 개 층 어디든 처리한다.** 6차시와 비교시킨다.

**③ `relight` — 반복 두 겹 (20분) — 오늘의 핵심**

`scan` 과 `light` 를 하나로 합친다. **바깥 반복이 층, 안쪽 반복이 유도등**이다.

```ts
player.onChat("relight", function (num1, num2) {
    checkFloor = num1
    let last = num2
    if (last < checkFloor) { last = checkFloor }
    lampTotal = 0
    agent.setSlot(1)
    loops.pause(200)
    for (let f = 0; f < last - checkFloor + 1; f++) {
        let y = 62 - checkFloor * 4
        for (let i = 0; i < 3; i++) {
            agent.teleport(world(-12 - i * 4, y, 8), WEST)
            loops.pause(300)
            agent.destroy(DOWN)
            loops.pause(200)
            agent.place(DOWN)
            loops.pause(200)
            lampTotal = lampTotal + 1
        }
        player.say(y)
        checkFloor = checkFloor + 1
    }
    player.say("총 설치")
    loops.pause(300)
    player.say(lampTotal)
})
```

**실행 전에 예상시킨다.** `relight 6 11` 은 여섯 개 층 × 세 개 = 열여덟 개.
실행하면 `lampTotal` 이 18로 끝난다. 맞추면 오늘 목표 달성이다.

**구조를 손가락으로 짚게 한다.**
- 바깥 `f` 는 몇 번 도는가 → 층 수
- 안쪽 `i` 는 몇 번 도는가 → 층마다 3번
- `y` 는 언제 다시 계산되는가 → 층이 바뀔 때마다
- `checkFloor` 는 어디서 커지는가 → 안쪽 반복이 다 끝난 뒤

**④ `patrol` (5분, 선택)**
층 홀 네 귀퉁이를 순찰하며 바닥 유무를 보고한다. `if (i == 0)` 형태로 자리를 고른다.

### 정리 · 25분

웹 교재 **지하 11층** 페이지에 기록한다.

- `scan 1 11` 이 찍은 Y 열한 개를 옮겨 적는다
- `relight 6 11` 의 예상 설치 개수와 실제 값을 적는다
- 바깥 반복과 안쪽 반복이 각각 무엇을 세는지 쓴다
- 이 명령 하나에 몇 차시 내용이 들어 있는지 세어본다

---

## 관찰 포인트

- 새 명령을 처음부터 짜지 않고 **이전 차시 코드를 찾아 가져오는가**
- 반복 두 겹에서 각 층위가 무엇을 세는지 구분하는가
- `y` 재계산 시점과 `checkFloor` 증가 시점을 짚어내는가
- 실행 전에 총 설치 개수를 계산하는가

## 확장 과제

- `relight` 의 유도등 개수 3을 매개변수로 빼려면 어디를 고쳐야 하는가.
- 층마다 유도등 간격을 다르게 하려면 무엇이 필요한가.
- `scan` 에 `free`(7차시)를 넣어 층마다 열린 방향을 보고하게 만들어본다.

## 자주 막히는 지점

| 상황 | 대응 |
|---|---|
| 한 층에만 다 설치된다 | `checkFloor = checkFloor + 1` 이 안쪽 반복 안에 있다 |
| 층은 바뀌는데 위치가 같다 | `y` 를 바깥 반복 밖에서 한 번만 계산했다 |
| 총 개수가 안 맞는다 | 초기화가 빠졌거나 증가가 안쪽에 없다 |
| 너무 오래 걸린다 | `relight 6 11` 은 18번 텔레포트다. 구간을 줄여 시험한다 |
| 블록이 모자란다 | 층당 3개 × 층 수. `need` 처럼 미리 계산 |

## 기대효과

- 개별 개념을 조합해 하나의 목적을 달성하는 설계 경험을 하며, 학습이 누적되었음을 스스로 확인한다.
- 중첩 구조에서 각 층위의 역할과 실행 시점을 구분하며 복잡한 코드를 읽는 능력이 생긴다.
- 기존 코드를 찾아 재사용하는 것이 새로 짜는 것보다 낫다는 판단을 하게 된다.
- 명령 하나가 스물두 개 작업을 대신하는 것을 확인하며 자동화의 효율을 체감한다.

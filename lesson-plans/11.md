## 오늘의 신호

> **-18 / 18 / -12**
> 신호가 갑자기 강해졌다. 12층이 코앞이다.
> 관제실은 마지막 점검을 지시한다. **1층부터 11층까지 전부 다시 훑을 것.**
> 층마다 명령을 만들면 열한 개다. 하나로 끝낼 방법이 있다.

---

## 목표

- **사고** 변수 값을 반복할 때마다 바꾸면 하나의 명령으로 여러 대상을 처리할 수 있음을 이해한다.
- **사고** 5차시의 계산식과 반복을 결합해 층 전체를 자동으로 순회하는 구조를 설계한다.
- **결과물** 1층부터 11층까지 순서대로 내려가며 좌표를 보고하는 `scan` 명령을 만든다.

---

## 흐름

### 도입 · 10분

5차시 `floor` 명령을 다시 실행한다. `targetFloor` 를 1로, 2로, 3으로 손으로 고쳐가며 11번 실행하게 한다.

**일부러 끝까지 시킨다.** 지루하다는 반응이 나올 때 멈춘다.

> "지금 뭘 반복했어?" → 숫자를 1씩 키우고 실행하는 것
> "그 두 개를 코드한테 시키면?"

### 전개 · 55분

**① 변수를 1 키우는 블록 (10분)**

```ts
let scanFloor = 1
scanFloor = scanFloor + 1
```

Variables에서 `set scanFloor to` 와 `change scanFloor by 1` 블록을 찾는다.
`scanFloor = scanFloor + 1` 이 왜 이상해 보이는지 이야기한다. 수학의 등호와 다르다.
**"오른쪽을 계산해서 왼쪽에 다시 넣는다"** 로 설명한다.

작은 실험으로 확인한다.

```ts
player.onChat("count", function () {
    scanFloor = 1
    for (let i = 0; i < 5; i++) {
        player.say(scanFloor)
        scanFloor = scanFloor + 1
    }
})
```

채팅창에 1 2 3 4 5 가 찍힌다.

**② `scan` 만들기 (20분)**

```ts
player.onChat("scan", function () {
    scanFloor = 1
    for (let i = 0; i < 11; i++) {
        let scanY = 62 - scanFloor * 4
        agent.teleport(world(-12, scanY, 8), WEST)
        loops.pause(700)
        player.say(scanY)
        scanFloor = scanFloor + 1
    }
    player.say("전층 스캔 완료")
})
```

실행하면 에이전트가 갱도를 따라 1층부터 11층까지 순서대로 내려간다.
채팅창에 58 54 50 46 42 38 34 30 26 22 18 이 차례로 찍힌다.

**이 장면이 오늘의 절정이다.** 5차시의 식, 6~10차시의 반복, 오늘의 누적이 한 줄로 묶였다.

**③ 왜 맨 앞에 `scanFloor = 1` 이 있는가 (10분)**

이 줄을 지우고 두 번 연속 실행한다. 두 번째는 12층부터 22층으로 내려간다(그리고 실패한다).
**초기화가 없으면 이전 값이 남는다.** 이걸 직접 보게 한다.

**④ 숫자 바꿔 실험 (15분)**

| 바꾼 곳 | 바꾼 값 | 예상 결과 | 실제 |
|---|---|---|---|
| 반복 횟수 11 | 5 | | |
| `scanFloor` 초기값 1 | 7 | | |
| `+ 1` | `+ 2` | | |

`+ 2` 로 바꾸면 홀수 층만 스캔한다. 이걸 아이가 발견하면 크게 짚어준다.

### 정리 · 25분

웹 교재 **지하 11층** 페이지에 기록한다.

- 채팅창에 찍힌 Y 열한 개를 옮겨 적는다
- `scanFloor = scanFloor + 1` 이 무슨 뜻인지 한 문장으로 쓴다
- 초기화 줄을 지우면 왜 안 되는지 한 줄로 쓴다
- 12층 Y를 계산해서 적는다. **다음 주에 거기로 간다**

---

## 관찰 포인트

- `변수 = 변수 + 1` 을 등식이 아니라 "다시 넣기"로 이해하는가
- 초기화가 필요한 이유를 두 번 실행 실험으로 설명하는가
- `+ 2` 로 바꿨을 때 홀수 층만 도는 이유를 말하는가

## 확장 과제

- 12층부터 1층까지 **거꾸로** 올라가게 하려면 무엇을 바꿔야 하는가.
- 스캔하면서 각 층에 표식을 남기려면 어디에 무엇을 넣어야 하는가. (10차시 `tag` 활용)
- `loops.pause(700)` 을 100으로 줄이면 어떻게 되는가. 왜 그런가.

## 자주 막히는 지점

| 상황 | 대응 |
|---|---|
| 계속 같은 층만 간다 | `scanFloor = scanFloor + 1` 이 반복 밖에 있다 |
| 두 번째 실행이 이상하다 | 초기화 줄이 빠졌다. 이건 일부러 보여줄 장면이다 |
| 에이전트가 벽에 박힌다 | `scanFloor` 가 12를 넘었다. 반복 횟수를 확인한다 |
| 너무 빨라서 안 보인다 | `loops.pause` 를 700 이상으로 |

## 기대효과

- 변수 값이 시간에 따라 변한다는 개념을 익히며, 정적인 값에서 동적인 값으로 이해가 넓어진다.
- 하나의 명령으로 여러 대상을 처리하는 구조를 설계하며 자동화의 효율을 체감한다.
- 초기화의 필요성을 실패로 배우며, 프로그램의 상태(state)라는 개념에 처음 닿는다.
- 지금까지 배운 좌표·변수·계산·반복이 한 코드 안에서 맞물리는 것을 확인하며 학습이 누적되었음을 스스로 안다.

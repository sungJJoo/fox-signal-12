## 오늘의 신호

> **0 / 22 / 22**
> 10층은 갈림길이 많다. 에이전트가 어디를 지나왔는지 관제실에서는 알 수 없다.
> 같은 길을 두 번 가고 있는지도 모른다.
> **지나온 자리에 표식을 남겨야 한다.**

---

## 목표

- **사고** 에이전트 인벤토리가 칸으로 나뉘어 있고, 칸을 고르는 것이 곧 재료를 고르는 것임을 안다.
- **사고** 하나의 명령 안에서 재료를 바꿔가며 패턴을 만드는 구조를 이해한다.
- **결과물** 간격을 조절할 수 있는 경로 표식 `tag` 와 두 재료를 번갈아 쓰는 `stripe` 를 만든다.

---

## 흐름

### 도입 · 10분

에이전트 인벤토리를 연다. 슬롯 1에 석재, 슬롯 2에 색 블록이 들어 있다.

> "지금까지는 계속 슬롯 1만 썼어. 그럼 슬롯 2는 언제 쓰는 거야?"

`sig10` 으로 10층에 보낸다. 갈림길이 여러 개 보인다.

> "여기서 길을 잃으면 어떻게 돼? 우리는 화면으로만 보고 있잖아."

### 전개 · 55분

**① 슬롯을 바꿔 놓아보기 (10분)**

```ts
agent.setSlot(1)
agent.destroy(DOWN)
agent.place(DOWN)
agent.move(FORWARD, 1)
agent.setSlot(2)
agent.destroy(DOWN)
agent.place(DOWN)
```

두 칸에 서로 다른 블록이 깔린다. `setSlot` 숫자 하나가 재료를 바꾼다는 걸 눈으로 확인한다.

**② 슬롯을 안 바꾸면 (5분)**
`setSlot(2)` 를 지우고 실행한다. 두 칸이 같은 블록이 된다.
**`setSlot` 을 안 쓰면 마지막에 고른 칸이 계속 유지된다.** 이걸 짚어준다.

**③ `tag` 만들기 (15분)**

```ts
let tagCount = 5
let tagGap = 4

player.onChat("tag", function () {
    for (let i = 0; i < tagCount; i++) {
        agent.setSlot(2)
        loops.pause(200)
        agent.destroy(DOWN)
        loops.pause(300)
        agent.place(DOWN)
        loops.pause(300)
        agent.move(FORWARD, tagGap)
        loops.pause(400)
    }
    player.say("경로 표식 완료")
})
```

6차시 `light` 와 구조가 똑같다. 재료만 다르다. 아이가 알아채면 좋다.

**④ `stripe` 만들기 (20분)**

```ts
player.onChat("stripe", function () {
    for (let i = 0; i < 6; i++) {
        agent.setSlot(1)
        loops.pause(200)
        agent.destroy(DOWN)
        loops.pause(300)
        agent.place(DOWN)
        loops.pause(300)
        agent.move(FORWARD, 1)
        loops.pause(300)
        agent.setSlot(2)
        loops.pause(200)
        agent.destroy(DOWN)
        loops.pause(300)
        agent.place(DOWN)
        loops.pause(300)
        agent.move(FORWARD, 1)
        loops.pause(300)
    }
    player.say("줄무늬 경로 완성")
})
```

반복 한 번에 **두 칸**이 깔린다. 반복 6번인데 길이는 12칸이다. 이걸 실행 전에 예상하게 한다.

**⑤ 나만의 무늬 (5분)**
반복 횟수와 슬롯 순서를 바꿔 자기만의 무늬를 만들게 한다. 잘 나온 화면을 다 같이 본다.

### 정리 · 25분

웹 교재 **지하 10층** 페이지에 기록한다.

- 반복 6번인데 길이가 12칸인 이유를 한 줄로 쓴다
- `setSlot` 을 안 쓰면 어떻게 되는지 한 줄로 쓴다
- 줄무늬 경로 스크린샷을 저장한다 (파일명 `10_이름.png`)

## 관찰 포인트

- 슬롯 번호와 재료의 관계를 자기 말로 설명하는가
- `setSlot` 을 생략했을 때 무슨 일이 일어나는지 아는가
- 반복 횟수와 실제 길이가 다른 이유를 반복 안의 이동 횟수로 설명하는가

## 확장 과제

- 슬롯 3에 또 다른 블록을 넣고 세 가지 색으로 무늬를 만든다.
- `tagGap` 을 1로 하면 `tag` 와 `stripe` 는 무엇이 달라지는가.
- 표식을 바닥이 아니라 벽에 남기려면 `place(DOWN)` 을 어떻게 바꿔야 하는가.

## 자주 막히는 지점

| 상황 | 대응 |
|---|---|
| 계속 같은 블록만 깔린다 | `setSlot` 이 반복 밖에 한 번만 있다. 안으로 넣는다 |
| 슬롯 2가 비었다 | 에이전트 인벤토리에 색 블록을 넣는다 |
| 코드가 너무 길어 헷갈린다 | 반복 안의 한 묶음(슬롯→부수기→놓기→이동)을 색으로 표시해준다 |
| 블록이 중간에 떨어진다 | 재료가 떨어졌다. 64개씩 채운다 |

## 기대효과

- 자원을 선택해서 쓰는 개념을 익히며, 같은 명령도 준비 상태에 따라 결과가 달라진다는 것을 안다.
- 반복 한 번에 여러 동작이 묶인다는 것을 이해하고, 반복 횟수와 결과량을 구분해 계산한다.
- 이전 차시 구조를 재사용하면서 재료만 바꿔 새 결과를 만드는 경험을 한다. 코드 재사용의 첫 감각이다.
- 자기만의 무늬를 만들며 정답이 하나가 아닌 과제에서 표현하는 즐거움을 얻는다.

> 층마다 명령을 하나씩 만들면 11개가 필요하다. **하나로 끝낼 방법은 없을까?**

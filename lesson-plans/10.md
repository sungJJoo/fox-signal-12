## 오늘의 신호

> 10층은 갈림길이 많다. 갱도에서 신호 지점까지 길을 깔아야 한다.
>
> 몇 칸을 깔아야 할까. 눈대중으로 하면 모자라거나 남는다.
> **좌표를 알고 있는데 왜 세고 있지?**

## 목표

- **사고** 두 좌표의 차가 거리이고, 그 부호가 방향이라는 것을 이해한다.
- **사고** 계산한 값을 코드에 넘겨 필요한 만큼만 작업하게 만든다.
- **결과물** 거리를 계산하는 `dist` 와 방향을 받아 길을 까는 `roadx` `roadz` 를 만든다.

## 흐름

### 도입 · 10분

칠판에 두 좌표를 쓴다.

```
갱도 입구   X = -12,  Z = 8
10층 신호   X =   0,  Z = 22
```

> "여기서 저기까지 몇 칸이야?"

아이들이 세기 시작한다. 잠깐 두었다가 멈춘다.

> "숫자를 알고 있잖아. 빼면 되지 않아?"

```
dx = 0 - (-12) = 12
dz = 22 - 8    = 14
```

마이너스를 빼면 더해진다는 걸 여기서 확인한다. 「마을을 지켜라」의 좌표평면이 여기서 다시 나온다.

### 전개 · 55분

**① `dist` (15분) — 오늘의 핵심**

```ts
let shaftX = -12
let shaftZ = 8

player.onChat("dist", function (num1, num2) {
    let dx = num1 - shaftX
    let dz = num2 - shaftZ
    player.say("X 차이")
    loops.pause(300)
    player.say(dx)
    loops.pause(400)
    player.say("Z 차이")
    loops.pause(300)
    player.say(dz)
})
```

여러 층의 신호 좌표를 넣어보며 표를 채운다.

| 목표 지점 | dx | dz | X는 어느 쪽? | Z는 어느 쪽? |
|---|---|---|---|---|
| `dist 0 22` (10층) | | | | |
| `dist -28 4` (9층) | | | | |
| `dist -18 -12` (11층) | | | | |

**부호를 읽는 연습이 오늘의 핵심이다.** 양수면 좌표가 커지는 쪽, 음수면 작아지는 쪽이다.

**그리고 하나 더** — 차이가 12라고 12칸을 깔면 한 칸이 모자란다.
−12부터 0까지는 −12, −11, ... , 0 으로 **13칸**이다. 9차시에서 배운 `끝 − 시작 + 1` 이 여기서 또 나온다.
손가락으로 세어 확인시킨 뒤 넘어간다.

**② `roadx` — 방향을 숫자로 받기 (20분)**

```ts
player.onChat("roadx", function (num1, num2) {
    let len = num1
    if (len < 1) { len = 1 }
    let step = -1
    if (num2 == 1) {
        step = 1
    }
    agent.setSlot(1)
    loops.pause(200)
    for (let i = 0; i < len; i++) {
        agent.teleport(world(shaftX + i * step, 22, shaftZ), WEST)
        loops.pause(300)
        agent.destroy(DOWN)
        loops.pause(200)
        agent.place(DOWN)
        loops.pause(200)
    }
    player.say("가로 길 완성")
})
```

`num2` 가 1이면 `step` 이 1, 아니면 −1이다. **`i * step` 이 방향을 뒤집는다.**

`dist` 로 잰 `dx = 12` 에 1을 더해 넣는다. 부호가 양수였으니 방향은 1.

```
roadx 13 1
```

끝나면 채팅에 도착한 X가 찍힌다. **0** 이다. 이 값을 `roadEndX` 변수가 기억한다.

**방향을 반대로 넣어보게 한다.** `roadx 13 0` → 반대편으로 깔린다. 왜인지 설명하게 한다.

**③ `roadz` — 이어 깔기 (10분)**

여기가 오늘의 두 번째 고비다. `roadz` 를 `roadx` 처럼 갱도(`shaftX`)에서 시작하게 만들면
두 길이 갱도에서 각각 뻗어나가 **L자가 아니라 십자**가 된다.

```ts
agent.teleport(world(roadEndX, 22, shaftZ + i * step), WEST)
```

`roadx` 가 끝난 자리에서 이어야 한다. 4차시에서 배운 변수가 여기서 쓰인다.
**일부러 `shaftX` 로 만들어 실행시킨 뒤** 십자가 되는 걸 보여주고 고치게 한다.

`dz = 14` 니까 15칸.

```
roadz 15 1
```

**④ L자 완성 (5분)**
`roadx 13 1` → `roadz 15 1` 을 연달아 실행하면 갱도에서 신호 지점 `(0, 22)` 까지 L자 길이 정확히 닿는다.
**아무것도 세지 않았다. 전부 계산으로 나왔다.**

**⑤ `tag` (5분, 선택)**
색 블록으로 일정 간격 표식. 슬롯 2를 쓴다.

### 정리 · 25분

웹 교재 **지하 10층** 페이지에 기록한다.

- `dist` 표 세 줄을 채운다 (dx, dz, 방향)
- 마이너스를 뺐을 때 왜 더해지는지 한 줄로 쓴다
- 차이가 12인데 왜 13칸인지 한 줄로 쓴다
- `roadz` 가 `roadEndX` 를 안 쓰면 길이 어떤 모양이 되는지 적는다
- L자 길 화면을 캡처해 저장한다 (`10_이름.png`)

## 관찰 포인트

- 세지 않고 빼서 구하는가
- 부호를 보고 방향을 판단하는가
- `roadx` 의 방향값을 잘못 넣었을 때 원인을 `step` 에서 찾는가
- `dist` 결과를 그대로 `roadx` 에 넘기는 흐름이 자연스러운가

## 확장 과제

- `dist` 가 음수를 줄 때 방향값을 자동으로 정하게 하려면 무엇이 필요한가.
- 대각선으로 바로 가려면 `roadx` 와 `roadz` 를 어떻게 합쳐야 하는가. (8차시 `raft` 힌트)
- 갱도가 아니라 **지금 에이전트 자리**에서 거리를 재려면 무엇이 더 필요한가.

## 자주 막히는 지점

| 상황 | 대응 |
|---|---|
| dx 부호를 반대로 읽는다 | `목표 − 현재` 순서다. 순서를 바꾸면 부호가 뒤집힌다 |
| 길이 반대편으로 깔린다 | 방향값을 확인. 1이 아니면 전부 −1이 된다 |
| 두 길이 십자가 된다 | `roadz` 가 `roadEndX` 대신 `shaftX` 를 쓰고 있다. 일부러 겪는 실패다 |
| 한 칸이 모자란다 | `+1` 을 안 했다. 차이가 12면 칸은 13개 |
| 홀 밖으로 나간다 | 층 홀은 X 2 까지다. `tag 5 4` 는 X 4 로 나가서 벽에 박힌다. `tag 4 4` 로 |
| `==` 블록을 못 찾는다 | Logic 카테고리의 비교 블록 |
| 표식이 안 보인다 | 슬롯 2가 비었거나 어두운 색이다 |

## 기대효과

- 측정 대신 계산으로 값을 구하는 태도가 생긴다. 좌표가 실용적인 도구가 된다.
- 음수의 뺄셈을 실제 상황에서 다루며 「마을을 지켜라」의 좌표평면 학습과 연결된다.
- 부호가 방향을 뜻한다는 것을 코드 동작으로 확인하며 수 개념이 공간 감각과 이어진다.
- 계산 도구와 실행 도구를 나눠 만들고 결과를 넘겨 쓰며, 작업을 단계로 나누는 사고를 익힌다.

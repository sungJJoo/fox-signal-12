# 강의 지도안 — 12차시 한눈에

**에이전트와 함께해요 2 — 지하 12층** | 초등 고학년 · 1탄 수료생 | 12차시 × 90분 | 담당 박성주

각 차시는 도입 10분 · 전개 55분 · 정리 25분 구조다.
좌표 기준값과 코딩 범위는 저장소 루트의 `context-notes.md` 에 있다.

---

## 전제 — 아이들이 이미 하고 오는 것

| 프로그램 | 배우고 오는 것 |
|---|---|
| 마을을 지켜라 | 좌표 · 좌표평면 이론, 직업별 장문 코드, 방어 시스템 설계 |
| 에이전트와 함께해요 (1탄) | `move` `turn` `place` `destroy` `collectAll` `setSlot` · `for` · `if + detect` · 중첩 반복 · 통합 루틴 |

**이 목록은 가르치지 않는다. 1차시부터 그냥 쓴다.**
좌표 보기 설정, 채팅창 여는 법, MakeCode 여는 법도 안내하지 않는다.

## 난이도 곡선

```
1~3차시    값을 바깥에서 넣는다           절대 좌표 · 매개변수
4~5차시    값을 기억하고 계산한다          변수 · 식        ← 첫 도약 ★
6~8차시    계산으로 자리를 만든다          반복 변수 · 면
9~10차시   값을 쌓고 잰다                누적 · 거리
11차시     전부 합쳐 스스로 돌린다         통합            ← 둘째 도약 ★
12차시     내 도구를 만든다               설계와 발표
```

**5차시와 11차시에서 이해가 갈린다.** 두 차시는 다른 활동을 줄여서라도 핵심 활동을 지킨다. 뒤처지는 아이가 나오면 다음 주 도입 5분을 복습에 쓴다.

## 1탄과 무엇이 다른가 — 매 차시 짚어줄 것

| | 1탄 | 2탄 |
|---|---|---|
| 숫자 바꾸기 | MakeCode 열고 → 고치고 → 저장 | 채팅에 `dive 5` |
| 에이전트 위치 | 항상 내 옆 (`teleportToPlayer`) | 좌표로 어디든 (`world`) |
| 반복의 `i` | 횟수 세기만 | 좌표 계산의 재료 |
| 결과 | 만들어지는 것 | 만들어지고 **숫자로 보고된다** |
| 명령 | 하나의 동작 | 입력에 따라 여러 형태로 동작 |

아이가 "이거 1탄에서 한 거잖아요"라고 하면 성공이다. 그때 **무엇이 달라졌는지** 되물어준다.

## 매 차시 공통 운영 원칙

**설명보다 실패를 먼저.** 2차시 숫자 없이 실행, 4차시 변수를 `onChat` 안에 만들기, 6차시 Y에 `i` 넣기, 7차시 초기화 누락, 8차시 블록 부족은 전부 **일부러 겪게 하는 실패**다. 미리 알려주면 학습이 사라진다.

**실행 전에 계산시키기.** 이 프로그램은 좌표와 변수가 축이다. "실행하면 어디에 놓일까"를 매 차시 최소 세 번 종이에 적게 한다.

**코드는 계속 쌓인다.** 매주 새 프로젝트를 만들지 않는다. 11·12차시에 이전 코드를 복사해 쓰기 때문이다. **지난 프로젝트가 없는 아이는 통합을 못 한다.**

**정리 25분은 줄이지 않는다.** 웹 교재 기록이 아이가 가져가는 결과물이다.

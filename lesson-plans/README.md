# 강의 지도안 — 12차시 한눈에

프로그램 「지하 12층 — 신호를 따라서」 | 초등 고학년 | 12차시 × 90분 | 담당 박성주

각 차시 파일은 도입 10분 · 전개 55분 · 정리 25분 구조다.
좌표 기준값과 코딩 범위는 저장소 루트의 `context-notes.md` 에 있다.

## 난이도 곡선

```
1~3차시    좌표를 읽고 위치를 지정한다        ← 관찰
4~5차시    숫자를 이름과 규칙으로 바꾼다      ← 추상화 (첫 번째 도약)
6~10차시   규칙으로 결과물을 만든다           ← 적용
11차시     규칙을 스스로 반복시킨다           ← 자동화 (두 번째 도약)
12차시     전부 잇고 자기 것을 만든다         ← 통합
```

4~5차시와 11차시에서 이해가 갈린다. 이 세 차시는 뒤처지는 아이가 나오면 다음 주 도입 5분을 복습에 쓴다.

---

## 매 차시 공통 운영 원칙

**설명보다 실패를 먼저.** 6차시 `place` 실패, 7차시 무작정 전진, 10차시 `setSlot` 생략, 11차시 초기화 누락은 전부 **일부러 겪게 하는 실패**다. 미리 알려주면 학습이 사라진다.

**실행 전에 예상시키기.** "이거 실행하면 어떻게 될 것 같아?"를 매 차시 최소 세 번 묻는다.

**코드는 계속 쌓인다.** 매주 새 프로젝트를 만들지 않는다. 12차시에 이전 코드를 복사해 쓰기 때문이다.

**정리 25분은 줄이지 않는다.** 웹 교재 기록이 아이가 가져가는 유일한 결과물이다.

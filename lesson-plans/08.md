## 오늘의 신호

> 8층은 물에 잠겼다. 한 줄 다리로는 못 건넌다.
> 관제실은 넓은 **부교**를 요구한다.
>
> 1탄에서 사각형은 만들어봤다. 하지만 그건 테두리였다.
> 오늘은 **안까지 꽉 찬 면**을 만든다.

---

## 목표

- **사고** 선을 만드는 반복과 면을 만드는 반복의 차이를 구조로 설명한다.
- **사고** 두 반복 변수가 각각 어떤 축을 담당하는지 구분하고, 바꿔 넣었을 때를 예측한다.
- **결과물** 가로·세로를 받아 면을 채우는 `raft` 와 필요 블록을 미리 계산하는 `need` 를 만든다.

## 흐름

### 도입 · 10분 — 종이로

1탄의 `box` 를 떠올리게 한다.

> "1탄에서 만든 사각형, 안쪽이 차 있었어? 비어 있었어?"

테두리만 있었다. 네 변을 돌았으니까.

종이에 6×4 격자를 그리게 하고 묻는다.

> "이걸 다 채우려면 몇 칸이야?" → 24
> "한 줄이 6칸이고 그런 줄이 4개지. 그럼 반복을 어떻게 겹쳐야 해?"

### 전개 · 55분

**① `line` — 복습 (10분)**

6차시 방식 그대로다. `i` 하나로 한 줄.

```ts
let baseX = -10
let baseZ = -8

player.onChat("line", function (num1) {
    ...
    for (let i = 0; i < len; i++) {
        agent.teleport(world(baseX + i, 30, baseZ), WEST)
        loops.pause(300)
        agent.place(DOWN)
        loops.pause(250)
    }
})
```

시작 좌표를 변수로 뺐다. 6차시 확장 과제에서 나왔던 이야기다.

**② `raft` — 반복 겹치기 (25분) — 오늘의 핵심**

```ts
player.onChat("raft", function (num1, num2) {
    let w = num1
    let d = num2
    if (w < 1) { w = 1 }
    if (d < 1) { d = 1 }
    agent.setSlot(1)
    loops.pause(200)
    for (let i = 0; i < w; i++) {
        for (let j = 0; j < d; j++) {
            agent.teleport(world(baseX + i, 30, baseZ + j), WEST)
            loops.pause(250)
            agent.place(DOWN)
            loops.pause(200)
        }
    }
    player.say("부교 완성")
})
```

**실행 전에 좌표를 몇 개 계산하게 한다.**

| i | j | X | Z |
|---|---|---|---|
| 0 | 0 | | |
| 0 | 1 | | |
| 1 | 0 | | |
| 2 | 3 | | |

`raft 6 4` 를 실행하면 에이전트가 한 줄을 다 깔고 옆줄로 넘어간다.
**안쪽 반복이 다 돌아야 바깥 반복이 한 칸 간다.** 이 순서를 화면으로 보게 한다.

**i 와 j 바꿔 넣기** — `baseX + j`, `baseZ + i` 로 바꿔 실행한다. 가로세로가 뒤집힌다.
`raft 6 4` 와 `raft 4 6` 의 차이와 같은지 비교시킨다.

**③ `need` — 미리 계산 (10분)**

```ts
player.onChat("need", function (num1, num2) {
    let total = num1 * num2
    player.say("필요 블록")
    loops.pause(300)
    player.say(total)
    if (total > 64) {
        player.say("인벤토리 부족")
    } else {
        player.say("설치 가능")
    }
})
```

만들기 **전에** 재료가 되는지 확인하는 도구다.
`need 10 10` → 100 → 부족. 그래서 `raft 10 10` 은 중간에 멈춘다. 확인시킨다.

**④ `frame` (10분, 선택)**
테두리만 두른다. 1탄 `box` 와 결과는 비슷하지만 **좌표로 만든다**는 점이 다르다.
`raft` 와 `frame` 의 블록 수를 비교하게 한다.

### 정리 · 25분

웹 교재 **지하 8층** 페이지에 기록한다.

- `i` / `j` / `X` / `Z` 좌표 계산표를 채운다
- `raft 6 4` 와 `raft 4 6` 의 결과 차이를 적는다
- `need` 로 계산한 값과 실제 사용한 블록 수를 비교한다
- 부교 화면을 캡처해 저장한다 (`08_이름.png`)

## 관찰 포인트

- 바깥 반복과 안쪽 반복이 각각 어느 축인지 구분하는가
- 안쪽 반복이 다 돌아야 바깥이 한 칸 간다는 순서를 설명하는가
- 만들기 전에 `need` 로 재료를 확인하는 습관이 붙는가

## 확장 과제

- 한 변이 1인 경우(`raft 1 10`)는 무엇과 같은가.
- 부교를 2층으로 쌓으려면 반복을 하나 더 겹쳐야 하는가, 다른 방법이 있는가.
- `raft` 에 `destroy(DOWN)` 을 넣으면 어디서 필요하고 어디서 필요 없는가. (6층과 8층 비교)

## 자주 막히는 지점

| 상황 | 대응 |
|---|---|
| 한 줄만 깔린다 | 바깥 반복 안에 안쪽 반복이 안 들어갔다 |
| 대각선으로 깔린다 | `i` 와 `j` 를 같은 자리에 넣었다 |
| 중간에 멈춘다 | 블록 부족. `need` 로 먼저 확인 |
| 물 밖에 깔린다 | `baseX` `baseZ` 가 침수 구간을 벗어났다. 물 범위는 X −10~−2, Z −8~2 |
| 너무 오래 걸린다 | `loops.pause` 를 200으로. `raft 6 4` 도 24번 반복이다 |

## 기대효과

- 1차원 반복과 2차원 반복의 구조 차이를 이해하고, 선과 면을 코드로 구분해 다룬다.
- 두 변수가 각각 독립된 축을 담당하는 구조를 파악하며 좌표계 감각이 깊어진다.
- 실행 전에 필요 자원을 계산하는 도구를 스스로 만들며, 계획하고 착수하는 순서를 익힌다.
- 반복의 실행 순서를 화면으로 추적하며 코드가 도는 과정을 머릿속에 그리게 된다.

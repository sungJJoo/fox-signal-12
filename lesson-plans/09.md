## 오늘의 신호

> **-28 / 26 / 4**
> 9층은 바닥이 통째로 내려앉았다. 발 디딜 곳이 없다.
> 한 줄짜리 통로로는 부족하다. 네모난 **착륙 발판**을 만들어야 한다.

## 목표

- **사고** 사각형을 "한 변을 놓고 도는 것을 네 번 반복"으로 분해한다.
- **사고** 바깥 반복과 안쪽 반복이 각각 무엇을 세는지 구분한다.
- **결과물** 한 변의 길이를 변수로 정하는 `deck` 명령을 만든다.

## 흐름

### 도입 · 10분 — 코드 없이 종이로

**컴퓨터를 만지지 못하게 한다.** 종이에 정사각형을 그리게 하고 묻는다.

> "에이전트한테 이걸 그리라고 하려면 뭐라고 말해야 해? 순서대로 써봐."

아이들이 쓴 문장을 몇 개 읽는다. 거의 다 이렇게 나온다.
"6칸 가고, 오른쪽으로 돌고, 6칸 가고, 오른쪽으로 돌고, ..."

> "지금 뭘 네 번 반복했지?" → **6칸 가고 도는 것**
> "그럼 6칸 가는 건 뭐야?" → **한 칸 가는 걸 여섯 번**

반복이 두 겹이라는 것을 아이 입으로 먼저 나오게 한 뒤 코드로 간다.

### 전개 · 55분

**① 한 변만 만들기 (10분)**

```ts
for (let i = 0; i < 6; i++) {
    agent.place(DOWN)
    loops.pause(300)
    agent.move(FORWARD, 1)
    loops.pause(300)
}
```

실행하면 한 줄이 깔린다. 8차시 `bridge` 와 같은 구조다. 아이가 "이거 저번 거잖아"라고 하면 좋다.

**② 반복으로 감싸기 (20분)**

```ts
let deckSide = 6

player.onChat("deck", function () {
    agent.setSlot(1)
    loops.pause(200)
    for (let side = 0; side < 4; side++) {
        for (let i = 0; i < deckSide; i++) {
            agent.place(DOWN)
            loops.pause(300)
            agent.move(FORWARD, 1)
            loops.pause(300)
        }
        agent.turn(RIGHT_TURN)
        loops.pause(300)
    }
    player.say("착륙 발판 완성")
})
```

**`turn` 이 어디에 들어가야 하는지**가 오늘의 함정이다.

- 안쪽 반복 안에 넣으면 → 한 칸마다 돌아서 제자리를 맴돈다
- 바깥 반복 안, 안쪽 반복 **뒤**에 넣으면 → 사각형이 된다

틀린 위치로 먼저 실행시켜 제자리를 도는 걸 보여준 뒤 옮긴다.

**③ 변수 실험 (15분)**

| deckSide | 예상 한 변 칸 수 | 예상 총 블록 수 | 실제 |
|---|---|---|---|
| 4 | | | |
| 6 | | | |
| 9 | | | |

총 블록 수를 **계산으로** 먼저 구하게 한다. 한 변 × 4다. 실제로 몇 개 썼는지 인벤토리로 확인한다.

**④ 왜 모서리가 겹치는가 (10분)**
한 변 6칸씩 4번이면 24칸인데, 실제 사각형 둘레는 24칸이 아니다. 모서리가 겹친다.
이걸 발견하는 아이가 있으면 크게 짚어준다. 없으면 그냥 넘어간다.

### 정리 · 25분

웹 교재 **지하 9층** 페이지에 기록한다.

- 도입에서 종이에 쓴 문장을 옮겨 적는다
- 바깥 반복이 세는 것과 안쪽 반복이 세는 것을 각각 한 단어로 쓴다
- 발판 스크린샷을 저장한다 (파일명 `09_이름.png`)

---

## 관찰 포인트

- 사각형을 "변 4개"로 분해해서 말하는가
- `turn` 의 위치를 스스로 판단하거나, 틀렸을 때 원인을 찾는가
- `deckSide` 를 바꿨을 때 필요한 블록 수를 미리 계산하는가

## 확장 과제

- `4` 를 `3` 으로 바꾸면 무엇이 만들어지는가. `6` 으로 바꾸면? 각도가 맞는가.
- `RIGHT_TURN` 을 `LEFT_TURN` 으로 바꾸면 사각형이 어느 방향으로 그려지는가.
- 발판을 2층으로 쌓으려면 무엇을 더해야 하는가. (힌트: `move(UP, 1)` 을 어디에 넣을까)

## 자주 막히는 지점

| 상황 | 대응 |
|---|---|
| 제자리에서 빙빙 돈다 | `turn` 이 안쪽 반복 안에 들어갔다 |
| 한 변만 만들고 끝난다 | 바깥 반복이 없거나 `turn` 이 바깥 반복 밖에 있다 |
| 블록이 모자란다 | 한 변 × 4개가 필요하다. 슬롯 1을 64개로 채운다 |
| 사각형이 안 닫힌다 | 마지막 변에서 한 칸 더 가서 그렇다. 정상이다. 왜 그런지 물어본다 |

## 기대효과

- 복잡한 도형을 단순한 동작의 반복으로 분해하는 사고를 경험한다.
- 반복이 겹쳐 있을 때 각 층이 무엇을 세는지 구분하며, 구조를 층위로 읽는 능력이 생긴다.
- 코드를 짜기 전에 종이에 순서를 적는 습관을 익힌다. 설계가 구현보다 먼저라는 것을 안다.
- 필요한 재료의 양을 계산으로 예측하고 실제와 맞춰보며 수학과 코딩을 연결한다.

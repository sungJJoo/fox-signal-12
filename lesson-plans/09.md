## 오늘의 신호

> 9층은 바닥이 통째로 내려앉았다. 신호 지점만 섬처럼 남아 있다.
> 관제실은 두 가지를 요구한다.
>
> 하나, 여러 층을 순서대로 점검할 것.
> 둘, **재료가 얼마나 드는지 미리 계산할 것.**

## 목표

- **사고** `for` 가 키우는 `i` 와 내가 키우는 변수의 차이를 설명한다.
- **사고** 누적 변수의 값이 반복마다 어떻게 변하는지 추적한다.
- **결과물** 층별 재료를 합산하는 `total` 과 구간을 훑는 `down` `up` 을 만든다.

## 흐름

### 도입 · 10분

6차시 `drill` 을 다시 실행한다.

> "이건 1층부터 순서대로 갔지. 그럼 **5층부터 9층까지**만 가려면?"

`i` 는 항상 0부터 시작한다. 바꿀 수가 없다. `let f = i + 1` 로 억지로 맞췄던 걸 상기시킨다.

> "`i` 는 `for` 가 정해. 내가 못 정해.
> 내가 만든 변수를 내가 키우면 시작도 끝도 내가 정할 수 있어."

칠판에 쓴다.

```
sum = sum + 24      한 번 돌 때마다 24씩 쌓인다
f   = f + 1         한 번 돌 때마다 한 층 내려간다
f   = f - 1         거꾸로도 된다
```

### 전개 · 55분

**① `total` — 합계 만들기 (20분) — 오늘의 핵심**

```ts
let sum = 0

player.onChat("total", function (num1, num2) {
    let floors = num1
    let side = num2
    if (floors < 1) { floors = 1 }
    if (side < 2) { side = 2 }
    sum = 0
    for (let i = 0; i < floors; i++) {
        sum = sum + side * 4
        player.say(sum)
        loops.pause(500)
    }
    player.say("총 블록 수")
    loops.pause(300)
    player.say(sum)
})
```

`total 4 6` 을 실행하면 채팅창에 **24 → 48 → 72 → 96** 이 차례로 찍힌다.

**실행 전에 종이에 네 숫자를 적게 한다.** 맞추는 게 목적이다.

| 반복 | sum 계산 | sum 값 |
|---|---|---|
| 1번째 | 0 + 24 | |
| 2번째 | 24 + 24 | |
| 3번째 | | |
| 4번째 | | |

`sum = sum + 24` 가 수학의 등호와 다르다는 걸 여기서 짚는다.
**"오른쪽을 계산해서 왼쪽에 다시 넣는다."** 등호가 아니라 화살표에 가깝다.

**② `down` — 구간 훑기 (20분)**

시작 층과 끝 층을 둘 다 받는다.

```ts
let scanFloor = 1

player.onChat("down", function (num1, num2) {
    scanFloor = num1
    if (scanFloor < 1) { scanFloor = 1 }
    let last = num2
    if (last < scanFloor) { last = scanFloor }
    for (let i = 0; i < last - scanFloor + 1; i++) {
        let y = 62 - scanFloor * 4
        agent.teleport(world(-12, y, 8), WEST)
        loops.pause(600)
        player.say(scanFloor)
        loops.pause(200)
        player.say(y)
        scanFloor = scanFloor + 1
    }
    player.say("하강 점검 완료")
})
```

`down 5 9` → 5층부터 9층까지. 6차시 `drill` 로는 못 하던 일이다.

**반복 횟수 `last - scanFloor + 1`** 이 왜 그런지 묻는다.
5층부터 9층까지는 5, 6, 7, 8, 9로 **5개**다. 9 − 5 = 4가 아니라 5. `+1` 이 필요하다.
아이가 헷갈리면 손가락으로 세게 한다.

**③ `up` — 거꾸로 (10분)**
`scanFloor = scanFloor - 1` 로 바꾼다. `up 9 1` → 9층에서 1층으로 올라온다.
반복 횟수 식도 뒤집어야 한다. 여기서 한 번 더 걸린다. 스스로 고치게 둔다.

**④ `edge` 와 `deck9` (5분, 선택)**

`sig9` 로 가면 붕괴 구멍 한가운데 떠 있는 섬 위에 선다. 사방이 뚫려 있는 게 보인다.
`edge` 로 붕괴 가장자리(−28, 4)에 선 뒤 `deck9 6` 을 실행하면 **신호 지점을 둘러싸는 네모 발판**이 생긴다.

발판을 만들면서 사용한 블록을 `sum` 으로 세서 보고한다. `total` 로 예측한 값과 맞는지 확인한다.

### 정리 · 25분

웹 교재 **지하 9층** 페이지에 기록한다.

- `total 4 6` 의 sum 추적표를 채운다
- `sum = sum + 24` 를 한 문장으로 설명한다
- `down 5 9` 가 왜 다섯 번 도는지 적는다
- `total` 예측값과 `deck9` 실제 사용량을 비교한다

## 관찰 포인트

- `i` 와 직접 만든 변수의 차이를 설명하는가
- `sum = sum + x` 를 등호가 아니라 대입으로 읽는가
- 구간 개수 `끝 − 시작 + 1` 을 손가락으로라도 검증하는가
- `up` 의 반복 횟수 식을 스스로 뒤집는가

## 확장 과제

- `sum = sum + side * 4` 에서 `* 4` 는 무엇을 뜻하는가. 면을 채우려면 어떻게 바꿔야 하는가.
- 층마다 크기가 다르다면(`5층은 6, 6층은 8`) 지금 코드로 계산할 수 있는가.
- `down 9 5` 처럼 거꾸로 주면 어떻게 되는가. 방어 장치가 막아주는가.

## 자주 막히는 지점

| 상황 | 대응 |
|---|---|
| sum 이 매번 24만 나온다 | 초기화가 반복 안에 들어갔다 |
| 실행할 때마다 값이 커진다 | 초기화가 아예 없다 |
| 한 층 적게/많이 간다 | `+1` 문제다. 손가락으로 세어 확인 |
| 계속 같은 층에 있다 | `scanFloor = scanFloor + 1` 이 반복 밖에 있다 |
| `up` 이 무한히 돈다 | 반복 횟수 식을 안 뒤집었다 |

## 기대효과

- 변수 값이 시간에 따라 변한다는 개념을 익히며 정적인 값에서 동적인 값으로 이해가 넓어진다.
- 대입과 등호를 구분하며, 프로그래밍 기호가 수학 기호와 다를 수 있음을 안다.
- 구간의 개수를 세는 계산에서 흔히 하는 실수를 직접 만나고 검증하는 방법을 익힌다.
- 자원 소요를 미리 계산해 실행 전에 판단하는 태도를 기른다.

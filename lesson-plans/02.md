| 항목 | 내용 |
|---|---|
| 프로그램명 | 지하 12층 — 신호를 따라서 |
| 차시 | 2차시 · 지하 2층 |
| 활동명 | 첫 하강 — Y가 곧 깊이다 |
| 운영시간 | 90분 |
| 대상 | 초등 고학년 (5~6학년) |
| 담당 | 박성주 |

| 핵심 명령 | `dive` · `rise` |

---

## 오늘의 신호

> 갱도 뚜껑이 열렸다. 아래는 완전히 캄캄하다.
> 관제실 화면에 새 신호가 뜬다. **-12 / 54 / 14**
> 어제는 58이었는데 오늘은 54다. 신호가 더 아래로 내려갔다.

---

## 목표

- **사고** Y 숫자가 줄어드는 것과 "깊어진다"가 같은 뜻임을 이동 실험으로 확인한다.
- **사고** 반복 횟수를 바꾸면 이동 거리가 그만큼 달라진다는 관계를 찾아낸다.
- **결과물** 한 층을 정확히 내려가는 `dive` 명령과 되돌아오는 `rise` 명령을 만든다.

---

## 흐름

### 도입 · 10분

1차시 프로젝트를 불러온다. **새 프로젝트를 만들지 않는다.** 오늘부터 코드는 계속 쌓인다.

> "1층 신호는 58, 2층 신호는 54야. 4가 줄었어. 이게 우연일까?"

아직 답하지 않는다. 오늘 끝에 다시 물어볼 것이라고만 말한다.

### 전개 · 55분

**① 아래로 한 칸씩 (10분)**
`agent.move(DOWN, 1)` 을 하나만 만들어 실행한다. Y가 1 줄어드는 것을 화면에서 확인한다.

**② `dive` 만들기 (15분)**

```ts
player.onChat("dive", function () {
    for (let i = 0; i < 4; i++) {
        agent.move(DOWN, 1)
        loops.pause(300)
    }
    player.say("한 층 하강")
})
```

실행 전에 먼저 묻는다. **"이거 실행하면 Y가 얼마나 줄어들까?"** 예상을 말하게 한 뒤 실행한다.

**③ `rise` 만들기 (10분)**
`DOWN` 을 `UP` 으로 바꾸기만 하면 된다. 아이가 스스로 만들게 한다. 이게 오늘의 첫 성공 경험이다.

**④ 반복 횟수 실험 (15분)**
`4` 를 다른 숫자로 바꿔가며 실행한다. 아이가 표를 채운다.

| 반복 횟수 | 예상 Y 변화 | 실제 Y 변화 |
|---|---|---|
| 4 | | |
| 8 | | |
| 12 | | |

숫자와 결과가 정확히 맞아떨어진다는 걸 확인하는 게 목적이다.

**⑤ 층 규칙 발견 (5분)**
"`dive` 한 번이 한 층이야. 그럼 지하 5층까지 가려면 `dive` 를 몇 번 쳐야 해?"
계산하게 하고, 실제로 그만큼 쳐서 Y를 확인시킨다.

### 정리 · 25분

웹 교재 **지하 2층** 페이지에 기록한다.

- 반복 횟수 실험 표를 옮겨 적는다
- 지하 3층·4층·5층의 Y를 예상해서 적는다 (다음 차시에 확인한다)
- "`dive` 를 50번 치라고 하면 어떻게 할래?" 라는 질문에 한 줄로 답한다

---

## 관찰 포인트

- `dive` 실행 전에 결과 Y를 **예상**하고 말하는가
- 반복 횟수와 이동 칸 수가 1:1이라는 것을 자기 말로 설명하는가
- `rise` 를 힌트 없이 스스로 만들었는가

## 확장 과제

- `dive` 와 `rise` 를 번갈아 실행하면 제자리로 돌아오는가. 몇 번 반복해도 정확한가.
- `agent.move(DOWN, 4)` 한 줄과 `move(DOWN, 1)` 을 4번 반복하는 것은 결과가 같은가. 과정은?

## 자주 막히는 지점

| 상황 | 대응 |
|---|---|
| 에이전트가 안 내려간다 | 발밑이 막혀 있다. 아직 갱도가 안 뚫린 위치일 수 있다. `mark` 로 다시 불러 갱도 위에서 실행 |
| 4번 중 2~3번만 내려간다 | `loops.pause(300)` 이 빠졌다. 명령이 밀린 것이다 |
| 1차시 코드가 사라졌다 | 새 프로젝트를 만든 것. MakeCode 홈에서 이전 프로젝트를 다시 연다 |

## 기대효과

- 숫자가 커지고 작아지는 것과 공간에서의 위아래를 연결해 이해한다. 좌표가 추상적 기호에서 실제 위치로 바뀐다.
- 실행 전에 결과를 예상하고 실행 후에 맞춰보는 습관이 생긴다. 이것이 이후 모든 차시의 기본 자세가 된다.
- 반복 횟수와 결과의 비례 관계를 발견하며, 코드를 "고칠 수 있는 것"으로 인식한다.

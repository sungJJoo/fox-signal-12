# 강의 지도안 | 에이전트와 함께해요 2 — 지하 12층 | 2차시

| 항목 | 내용 |
|---|---|
| 차시 | 2차시 · 지하 2층 |
| 활동명 | 숫자를 실어 보낸다 — 채팅 명령 매개변수 |
| 운영시간 | 90분 |
| 신호 좌표 | -4 / 54 / -6 |
| 핵심 명령 | `dive` · `rise` · `fwd` · `dig` · `sig2` |
| 새로 배우는 것 | `onChat` 의 `num1` |
| 준비물 | 노트북, Minecraft Education, 웹 교재 QR, 1차시 프로젝트 |

---

## 오늘의 신호

> 2층 신호가 잡혔다. 그런데 층마다 내려갈 깊이가 다르다.
> 3층으로 보낼 때, 7층으로 보낼 때, 매번 코드를 열어 숫자를 고칠 것인가.
>
> 관제실 무전은 그렇게 하지 않는다. **명령에 숫자를 실어 보낸다.**

---

## 목표

- **사고** 코드에 박힌 숫자와 채팅으로 넘기는 숫자의 차이를 안다.
- **사고** 숫자를 주지 않았을 때 무슨 일이 일어나는지 확인하고 방어 장치를 스스로 넣는다.
- **결과물** 숫자를 받아 동작하는 명령 네 개를 만든다.

---

## 흐름

### 도입 · 10분

1탄에서 아이들이 겪은 일을 그대로 재현한다.

> "1탄에서 `path` 를 10칸에서 15칸으로 바꾸려면 어떻게 했었지?"

MakeCode 열고 → 숫자 찾고 → 고치고 → 저장하고 → 게임 돌아가서 실행. 다섯 단계다.

> "오늘부터는 이렇게 친다."

칠판에 쓴다.

```
dive 3
```

> "그러면 3이 코드 안으로 들어와. 코드는 한 번도 안 열어."

### 전개 · 55분

**① `num1` 블록 찾기 (10분)**

`on chat command` 블록에 마우스를 올리면 `num1` `num2` `num3` 이 나온다. 이걸 끌어다 쓴다.
MakeCode가 만드는 이름 그대로 `num1` 을 쓴다. 이름을 바꾸지 않는다.

```ts
player.onChat("dive", function (num1) {
    player.say(num1)
})
```

먼저 이것만 만들어 `dive 7` 을 쳐본다. 채팅창에 7이 찍힌다. **숫자가 들어왔다는 걸 눈으로 먼저 본다.**

**② 숫자 없이 쳐보기 (5분) — 일부러 실패**

그냥 `dive` 만 친다. 0이 찍힌다.

> "숫자를 안 주면 0이 들어와. 그럼 0층 내려가라는 뜻이니까 아무 일도 안 일어나."

여기서 방어 장치를 넣는다.

```ts
let downFloors = num1
if (downFloors < 1) {
    downFloors = 1
}
```

**③ `dive` 완성 (10분)**

한 층은 4칸이다. `num1` 층이면 `num1 × 4` 칸이다. 곱하기를 반복 횟수 자리에 넣는다.

```ts
for (let i = 0; i < downFloors * 4; i++) {
    agent.move(DOWN, 1)
    loops.pause(250)
}
```

`dive 1` → Y가 4 줄어든다. `dive 3` → 12 줄어든다. 예상하고 실행한다.

**④ `rise` `fwd` `dig` (25분)**

- `rise` — `DOWN` 을 `UP` 으로. 복사해서 두 글자만 고친다
- `fwd num1` — 앞으로 `num1` 칸
- `dig num1` — 앞으로 `num1` 칸 파며 전진 (1탄 조건 판단 재사용)

세 개 모두 방어 장치를 같이 넣는다. **같은 패턴을 네 번 반복하는 것이 오늘의 손기술이다.**

**⑤ `sig2` (5분)**
2층 신호 지점으로 가는 명령. Z가 마이너스인 것을 확인시킨다.

### 정리 · 25분

웹 교재 **지하 2층** 페이지에 기록한다.

- `dive` 를 1, 3, 5로 실행했을 때의 Y 변화를 표로 적는다
- 숫자 없이 `dive` 만 쳤을 때 무슨 일이 일어났는지 적는다
- 1탄에서 숫자를 바꾸던 방법과 오늘 방법을 비교해 한 줄로 쓴다

---

## 관찰 포인트

- `num1` 이 채팅에서 온 숫자라는 걸 자기 말로 설명하는가
- 곱하기를 반복 횟수 자리에 넣는 것을 스스로 하는가
- 방어 장치를 다른 명령에도 스스로 복사해 넣는가

## 확장 과제

- `dive 100` 을 치면 어떻게 되는가. 어디서 멈추는가. 왜인가.
- `dive -3` 처럼 음수를 넣으면? 방어 장치가 막아주는가.
- `dig` 에 `collectAll` 이 없으면 무엇이 달라지는가.

## 자주 막히는 지점

| 상황 | 대응 |
|---|---|
| `num1` 블록이 안 보인다 | `on chat command` 블록 위에 마우스를 올려야 나온다 |
| 숫자를 쳐도 반응이 없다 | 명령어와 숫자 사이에 **띄어쓰기 한 칸**. `dive3` 은 안 된다 |
| 항상 1층만 내려간다 | 방어 장치가 `if (x < 1)` 이 아니라 `x = 1` 로 되어 있다 |
| Y가 4가 아니라 1만 줄었다 | `* 4` 를 반복 횟수에 안 넣었다 |

## 기대효과

- 값을 코드 바깥에서 주입하는 개념을 처음 경험하며, 프로그램이 상황에 따라 다르게 동작할 수 있음을 안다.
- 잘못된 입력이 들어올 수 있다는 것을 알고 미리 막는 태도를 익힌다.
- 같은 구조를 네 번 반복해 만들며 패턴을 인식하고 손이 빨라진다.
- 1탄에서 겪던 불편이 실제로 해소되는 것을 경험하며 학습의 이유를 스스로 납득한다.

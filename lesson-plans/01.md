# 강의 지도안 | 지하 12층 — 신호를 따라서 | 1차시

| 항목 | 내용 |
|---|---|
| 프로그램명 | 지하 12층 — 신호를 따라서 |
| 차시 | 1차시 · 지하 1층 |
| 활동명 | 관제실 개소 — 좌표를 읽는다 |
| 운영시간 | 90분 |
| 대상 | 초등 고학년 (5~6학년) |
| 담당 | 박성주 |
| 신호 좌표 | -12 / 58 / 8 |
| 핵심 명령 | `mark` · `spin` |
| 새로 배우는 것 | X · Y · Z 좌표 읽기 |
| 준비물 | 노트북, Minecraft Education, 웹 교재 QR, 월드 `signal-12` |

---

## 오늘의 신호

> 3주 전부터 지하에서 신호가 올라온다.
> 신호는 언제나 같은 숫자 세 개만 반복한다.
>
> **-12 / 58 / 8**
>
> 연구소는 그것이 좌표라는 것을 알아냈다. 하지만 사람은 내려갈 수 없다.
> 내려갈 수 있는 건 에이전트뿐이다. 오늘부터 너는 관제실 오퍼레이터다.

---

## 목표

- **사고** 게임 화면의 숫자 세 개가 각각 무엇을 가리키는지 스스로 실험해서 알아낸다.
- **사고** 내 위치와 에이전트 위치가 다를 수 있다는 것을 좌표로 확인한다.
- **결과물** 관제 개시 명령 `mark` 를 만들고, 웹 교재 1층 페이지에 시작 좌표를 기록한다.

---

## 흐름

### 도입 · 10분

칠판이나 화면에 **-12 / 58 / 8** 세 숫자만 크게 띄운다. 아무 설명도 하지 않는다.

> "3주째 지하에서 이 신호만 올라와. 이게 뭘 뜻하는 것 같아?"

아이 답을 그대로 받는다. 정답을 알려주지 않는다. 월드에 접속하면 화면 위쪽에 똑같이 생긴 숫자 세 개가 있다는 것만 확인시킨다.

전체 12차시 흐름을 30초만 안내한다. 지하 12층까지 내려가는 것, 층 하나가 한 주라는 것.

### 전개 · 55분

**① 좌표 표시 켜기 (5분)**
설정 → 게임 → 좌표 보기 ON. 화면 왼쪽 위에 세 숫자가 나오는지 전원 확인.

**② 숫자 정체 밝히기 (15분) — 오늘의 핵심**
설명하지 말고 시키기만 한다.

- "앞으로 쭉 걸어봐. 세 숫자 중에 뭐가 변해?"
- "옆으로 걸어봐. 이번엔 뭐가 변해?"
- "제자리에서 점프해봐. 이번엔?"

세 번 시키면 아이가 직접 결론을 낸다. 그때 이름을 붙여준다. **X는 동서, Z는 남북, Y는 높이.**
그리고 신호 숫자로 돌아온다. "그럼 58은 뭐야?" → 높이. "우리는 지금 Y가 몇이야?" → 70쯤. "신호는 우리보다 위야 아래야?"

**③ MakeCode 열고 `mark` 만들기 (20분)**
`C` 키 → MakeCode → 새 프로젝트. `player.onChat` 블록과 `teleport agent to player` 블록을 찾아 연결한다.

```ts
player.onChat("mark", function () {
    agent.teleportToPlayer()
    loops.pause(400)
    player.say("관제 시작 지점 확보")
})
```

저장(`Ctrl+S`) → `T` 키 → `mark` 입력 → 에이전트가 옆에 나타나는지 확인.

**④ `spin` 추가 (10분)**
반복 블록을 처음 만난다. 4번 오른쪽으로 회전.

**⑤ 좌표 비교 (5분)**
에이전트를 멀리 보낸 뒤 내 좌표를 읽고, `mark` 를 실행한 뒤 다시 읽는다. 무엇이 같아졌나?

### 정리 · 25분

웹 교재 **지하 1층** 페이지를 QR로 연다.

- 오늘 관제를 시작한 좌표 세 개를 적는다
- 관찰 질문 세 개에 답한다
- "다음 층은 Y가 몇일까?" 예상 숫자를 하나 적는다

---

## 관찰 포인트

- 세 숫자 중 어떤 것이 높이인지 **스스로** 말할 수 있는가
- `mark` 실행 후 내 좌표와 에이전트 좌표가 거의 같아지는가
- 신호의 58이 우리보다 아래라는 것을 좌표로 설명하는가

## 확장 과제

- `spin` 의 반복 횟수를 4에서 8로 바꾸면 어떻게 될까. 먼저 예상하고 실행한다.
- 월드에서 Y가 가장 낮은 곳을 찾아본다. 얼마까지 내려가는가.

## 자주 막히는 지점

| 상황 | 대응 |
|---|---|
| 좌표가 화면에 안 보인다 | 설정 → 게임 → 좌표 보기. 월드 생성 시 켰어도 개별 확인 필요 |
| MakeCode가 안 열린다 | `C` 키. 안 되면 채팅창 `/code` |
| `mark` 를 쳐도 반응 없다 | 저장(`Ctrl+S`)을 안 했거나 명령어 철자가 다르다. 대소문자 구분됨 |
| 에이전트가 화면에 없다 | 첫 접속 시 스폰 안 된 상태. `mark` 가 바로 해결책이다 |

## 기대효과

- 게임 화면의 숫자를 정보로 읽는 태도가 생긴다. 좌표는 외우는 지식이 아니라 확인하는 도구가 된다.
- 실험으로 규칙을 알아내는 순서(해보기 → 관찰 → 결론)를 첫 차시부터 몸에 익힌다.
- 명령을 만들면 에이전트가 그대로 실행한다는 인과를 직접 확인하며 프로그램 전체의 동기를 얻는다.

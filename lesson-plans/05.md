---

## 오늘의 신호

> 관제실 기록관이 지금까지의 층별 Y를 표로 붙여놓았다.
>
> **58 · 54 · 50 · 46 · 42 ...**
>
> "매번 표에서 찾아 칠 거야? 12층 Y가 뭔지는 알아?"

---

## 목표

- **사고** 층별 Y 값에서 규칙을 찾아내고 식으로 표현한다.
- **사고** 아직 가보지 않은 층의 좌표를 계산으로 먼저 알아낸다.
- **결과물** 층 번호 하나로 어느 층이든 가는 `floor` 와, 층과 크기를 함께 받는 `build` 를 만든다.

---

## 흐름

### 도입 · 10분 — 종이로만

컴퓨터를 덮게 한다. 칠판에 숫자만 쓴다.

```
1층 → 58        5층 → ?
2층 → 54        9층 → ?
3층 → 50       12층 → ?
4층 → 46
```

5층은 바로 나온다. 9층부터 손으로 세기 시작한다. 12층에서 헷갈리는 아이가 나온다.

> "손으로 세면 되긴 해. 근데 100층이면? 규칙을 식으로 쓸 수 있을까?"

### 전개 · 55분

**① 규칙 찾기 (15분) — 여전히 종이로**

두 단계로만 유도한다.

1. "층이 1 늘 때마다 Y는 몇씩 변해?" → **4씩 줄어든다**
2. "그럼 **0층**이 있다면 Y는?" → 58 + 4 = **62**

여기까지 오면 아이가 식을 만든다.

```
Y = 62 - 층 × 4
```

종이에서 먼저 검산한다. 3층 → 50 맞다. 12층 → **14**.
**아직 아무도 12층에 못 갔는데 좌표는 이미 알아냈다.** 이 순간을 크게 짚어준다.

**② `depth` — 계산만 (10분)**

이동은 안 하고 계산 결과만 보고한다. 종이 계산과 맞는지 확인하는 도구다.

```ts
player.onChat("depth", function (num1) {
    let y = 62 - num1 * 4
    player.say(num1)
    loops.pause(300)
    player.say(y)
})
```

`depth 1` 부터 `depth 12` 까지 전부 쳐보며 종이 표와 대조한다.

**연산 순서 함정** — `62 - num1` 을 먼저 하고 `× 4` 를 하면 결과가 틀린다.
일부러 그렇게 만들어 실행시킨 뒤 종이 값과 비교하게 한다. 곱하기 블록이 빼기 블록 **안**에 들어가야 한다.

**③ `floor` — 계산해서 투입 (15분) — 오늘의 핵심**

```ts
let floorNow = 5

player.onChat("floor", function (num1) {
    floorNow = num1
    let y = 62 - floorNow * 4
    agent.teleport(world(-12, y, 8), WEST)
    loops.pause(500)
    player.say(floorNow)
    loops.pause(300)
    player.say(y)
})
```

`floor 1` 부터 `floor 12` 까지 순서대로 친다. 코드는 한 글자도 안 고친다.

| 층 | 예상 Y | 실제 Y |
|---|---|---|
| 1 | | |
| 6 | | |
| 9 | | |
| 12 | | |

3차시 `warp` 와 비교시킨다. `warp` 는 숫자 세 개를 쳤다. `floor` 는 하나만 친다.
**차이는 코드가 계산을 대신한다는 것이다.**

**④ `at` — 층 + X + Z (10분)**

```ts
player.onChat("at", function (num1, num2, num3) {
    let y = 62 - num1 * 4
    agent.teleport(world(num2, y, num3), WEST)
    ...
})
```

`at 7 -24 20` → 7층 신호 지점. Y는 안 친다. 코드가 만든다.

**⑤ `build` — 층과 크기 (5분, 선택)**

`build 9 6` → 9층 갱도 옆에 한 변 6짜리 발판. 계산과 1탄 건축이 하나로 붙는다.

### 정리 · 25분

웹 교재 **지하 5층** 페이지에 기록한다.

- 식 `Y = 62 - 층 × 4` 를 손으로 옮겨 적는다
- 1층부터 12층까지 Y를 **계산으로** 채운다 (게임으로 확인하기 전에)
- 연산 순서를 틀렸을 때 나온 값과 맞는 값을 나란히 적는다
- `warp` 와 `floor` 의 차이를 한 문장으로 쓴다

---

## 관찰 포인트

- "4씩 줄어든다"에서 멈추지 않고 **식**까지 만들었는가
- 12층 좌표를 게임보다 **계산으로 먼저** 알아냈는가
- 연산 순서를 틀렸을 때 종이 값과 대조해서 원인을 찾는가

## 확장 과제

- 지하 20층이 있다면 Y는? 계산하면 −18이다. 실제로 넣으면 어떻게 되는가. 왜인가.
- 층 간격이 4가 아니라 6이라면 식은 어떻게 바뀌는가. 코드에서 4를 6으로 바꿔 확인한다.
- `62` 를 다른 숫자로 바꾸면 무엇이 달라지는가. 그 숫자는 무엇을 뜻하는가.

## 자주 막히는 지점

| 상황 | 대응 |
|---|---|
| 계산 결과가 틀리다 | 곱하기가 빼기 **안**에 들어가야 한다. `62 − (층 × 4)` |
| Y가 음수로 나온다 | 층 번호가 15를 넘었다. 이 시설은 12층까지다 |
| `y` 변수를 못 만든다 | `onChat` 안의 지역 변수다. Variables에서 만든 뒤 안쪽에 넣는다 |
| 식은 맞는데 안 움직인다 | `world` 의 Y 자리에 `y` 블록을 안 끼웠다 |
| 층 대신 Y를 친다 | `floor 42` 가 아니라 `floor 5` 다. 무엇을 넘기는지 확인 |

## 기대효과

- 개별 값을 외우는 대신 규칙을 찾아 일반화하는 사고를 경험한다. 수학의 규칙성 단원과 직접 연결된다.
- 아직 관측하지 않은 값을 계산으로 예측하고 실제와 맞춰보며 예측의 힘을 체감한다.
- 연산 순서가 결과를 바꾸는 것을 직접 확인하며 사칙연산 우선순위를 몸으로 익힌다.
- 입력 하나로 열두 가지 결과를 만들며, 코드가 확장된다는 것의 의미를 처음으로 정확히 이해한다.

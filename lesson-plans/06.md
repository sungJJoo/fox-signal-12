## 오늘의 신호

> **0 / 38 / 16**
> 6층은 조명이 전부 죽어 있다. 화면이 새까맣다.
> 에이전트는 볼 수 있지만 관제실은 아무것도 못 본다.
> 유도등을 바닥에 심어야 한다.

---

## 목표

- **사고** 블록을 놓으려면 그 자리가 비어 있어야 한다는 조건을 실패를 통해 발견한다.
- **사고** 반복 횟수와 이동 거리를 각각 변수로 빼면 결과물의 모양을 두 방향으로 조절할 수 있음을 안다.
- **결과물** 유도등 개수와 간격을 자유롭게 바꿀 수 있는 `light` 명령을 만든다.

## 흐름

### 도입 · 10분

먼저 `sig6` 로 6층에 보낸다. 화면이 새까맣다. 아이들이 웅성거린다.

> "에이전트는 지금 뭔가를 보고 있어. 근데 우리는 못 봐. 관제실은 뭘 할 수 있을까?"

에이전트 인벤토리를 연다(에이전트 우클릭). 슬롯 1에 글로우스톤이 들어 있는 것을 확인시킨다.

### 전개 · 55분

**① 일부러 실패시키기 (10분)**

먼저 이 코드만 만들어 실행한다.

```ts
agent.setSlot(1)
agent.place(DOWN)
```

**아무 일도 안 일어난다.** 왜인지 묻는다.

답이 안 나오면 힌트를 준다. "에이전트 발밑에 지금 뭐가 있어?" → 바닥 돌.
자리가 이미 차 있으면 놓을 수 없다.

**② `destroy` 를 앞에 붙여 해결 (10분)**

```ts
agent.setSlot(1)
agent.destroy(DOWN)
agent.place(DOWN)
```

이번엔 된다. **순서가 결과를 만든다**는 걸 방금 실패로 배웠다.
순서를 거꾸로(`place` → `destroy`) 해보게 하면 놓았다가 다시 부순다. 이것도 보여준다.

**③ `light` 완성 (20분)**

```ts
let lampCount = 5
let lampGap = 3

player.onChat("light", function () {
    agent.setSlot(1)
    loops.pause(200)
    for (let i = 0; i < lampCount; i++) {
        agent.destroy(DOWN)
        loops.pause(300)
        agent.place(DOWN)
        loops.pause(300)
        agent.move(FORWARD, lampGap)
        loops.pause(400)
    }
    player.say("유도등 설치 완료")
})
```

실행하면 어둠 속에 유도등이 일정 간격으로 켜진다. 이 장면이 오늘의 보상이다.

**④ 변수 두 개를 따로 실험 (15분)**

| lampCount | lampGap | 예상 결과 | 실제 결과 |
|---|---|---|---|
| 5 | 3 | | |
| 10 | 3 | | |
| 5 | 6 | | |
| 3 | 1 | | |

두 변수가 **다른 것**을 조절한다는 걸 표로 확인한다. 하나는 개수, 하나는 간격이다.

### 정리 · 25분

웹 교재 **지하 6층** 페이지에 기록한다.

- 변수 실험 표를 옮긴다
- "`destroy` 를 빼면 왜 안 될까?" 한 줄로 답한다
- 6층 유도등 스크린샷을 찍어 파일로 저장한다 (파일명 `06_이름.png`)

---

## 관찰 포인트

- `place` 가 실패한 이유를 "자리가 차 있어서"로 설명하는가
- `lampCount` 와 `lampGap` 이 각각 무엇을 바꾸는지 구분하는가
- 실행 전에 유도등이 어디까지 깔릴지 예상하는가

## 확장 과제

- 유도등을 10개, 2칸 간격으로 깔려면 두 숫자를 어떻게 바꿔야 하는가. 마지막 유도등은 몇 칸 앞에 있게 되는가.
- `lampGap` 을 0으로 하면 어떻게 되는가. 왜 그런가.
- 슬롯 1을 다른 블록으로 바꾸면 유도등 대신 무엇이 깔리는가.

## 자주 막히는 지점

| 상황 | 대응 |
|---|---|
| 아무것도 안 놓인다 | 슬롯 1이 비었다. 에이전트 우클릭 → 인벤토리 확인 |
| 첫 개만 놓이고 멈춘다 | `loops.pause` 가 빠졌다 |
| 에이전트가 벽에 박힌다 | `lampGap` 이 너무 커서 홀 밖으로 나갔다. `sig6` 로 되돌린다 |
| 여전히 화면이 어둡다 | 글로우스톤이 아니라 다른 블록이 슬롯 1에 있다 |

## 기대효과

- 실패를 먼저 겪고 원인을 찾는 순서를 경험하며, 오류를 두려워하지 않는 태도가 생긴다.
- 명령의 순서가 결과를 결정한다는 것을 눈으로 확인하며 순차 구조의 의미를 이해한다.
- 하나의 코드에서 서로 다른 두 변수가 각기 다른 속성을 조절하는 구조를 파악한다.
- 어두운 공간이 자기 코드로 밝아지는 경험을 통해 코딩의 결과가 환경을 바꾼다는 것을 체감한다.

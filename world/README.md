# 월드 구성 안내

「지하 12층 — 신호를 따라서」 전용 월드를 만드는 절차다. 한 번 만들어두고 매 기수 복제해서 쓴다.

---

## 1. 월드 생성 설정

| 항목 | 값 |
|---|---|
| 월드 이름 | `signal-12` |
| 게임 모드 | **크리에이티브** (건설 시) → 수업 중에는 **서바이벌** |
| 난이도 | 평화로움 |
| 좌표 보기 | **켜기** (필수. 이 프로그램 전체가 좌표로 돌아간다) |
| 시간 | 항상 낮 |
| 날씨 변화 | 끄기 |
| 즉시 존중 | 켜기 |
| 시드 | 지정하지 않는다 |

**좌표 보기를 반드시 켠다.** 1차시 활동 전체가 화면 좌표를 읽는 것이다.

**평화로움**으로 두는 이유는 지하가 어두워 몹이 계속 나오기 때문이다. 6층은 일부러 조명이 없다.

---

## 2. 지상 관제실 위치 정하기

월드에 들어가서 평평한 곳을 찾은 뒤, `/tp` 로 **X = -12, Z = 8** 근처로 이동한다.

```
/tp -12 ~ 8
```

여기가 갱도 입구다. 지상 Y가 얼마인지 화면에서 확인해둔다. 보통 63~70 사이다.
지형이 이 좌표에서 산이나 바다면 다른 곳에 월드를 새로 만드는 편이 빠르다.

---

## 3. 건설 코드 실행

`world/build.js` 를 **별도의 MakeCode 프로젝트**에 붙여넣는다. 수업용 프로젝트와 섞지 않는다.

채팅창(`T`)에서 순서대로 실행한다.

```
buildall
```
지하 1~12층과 수직 갱도를 만든다. **1~2분** 걸리고 그동안 화면이 버벅인다. 정상이다.

렉이 너무 심하면 `buildall` 대신 `buildone` 을 쓴다. `buildFloor` 변수를 1부터 12까지 바꿔가며 열두 번 실행한다.

```
props
```
층별 장치를 설치한다. 조명, 7층 붕괴 구간, 8층 침수, 9층 바닥 붕괴, 12층 신호원.

```
check
```
1층부터 12층까지 에이전트를 순서대로 보내며 눈으로 확인한다. 층당 1.2초씩, 총 15초 정도다.

## 4. 만들어지는 구조

```
지상  Y 63~79   갱도 (3x3 수직 통로)
─────────────────────────────
1층   Y 58      관제실 개소
2층   Y 54      첫 하강
3층   Y 50      좌표 투입
4층   Y 46      변수
5층   Y 42      층 계산기
6층   Y 38      조명 없음  ← 일부러 어둡다
7층   Y 34      통로 붕괴  ← 조약돌 장애물
8층   Y 30      침수      ← 바닥 걷어내고 물
9층   Y 26      바닥 붕괴  ← 바닥 걷어냄
10층  Y 22      갈림길
11층  Y 18      전층 스캔
12층  Y 14      신호원    ← 철블록 단상 + 발광석
```

각 층 홀 크기는 **가로 33칸 × 세로 3칸 × 세로 39칸** (X -30~2, Z -14~24) 이다.
층과 층 사이는 돌 한 겹으로 막혀 있고, 갱도만 세로로 관통한다.

## 5. 에이전트 슬롯 준비

차시마다 필요한 재료가 다르다. **수업 시작 전에 미리 넣어둔다.**
에이전트를 우클릭하면 인벤토리가 열린다.

| 차시 | 슬롯 1 | 슬롯 2 | 비고 |
|---|---|---|---|
| 1~5 | — | — | 재료 필요 없음 |
| 6 | 글로우스톤 64 | — | 유도등 |
| 7 | 글로우스톤 64 | — | 6차시 유지 |
| 8 | **석재 64** | — | 글로우스톤에서 교체 |
| 9 | 석재 64 | — | 발판. 64개로 채울 것 |
| 10 | 석재 64 | **색 블록 64** | 양털·유약 테라코타 등 눈에 띄는 것 |
| 11 | — | — | 재료 필요 없음 |
| 12 | 석재 64 | **글로우스톤 64** | 슬롯 2를 교체 |

10차시 슬롯 2는 어두운 지하에서도 확 눈에 띄는 색을 고른다. 노란색·빨간색 계열이 좋다.

## 6. 수업 중 복구

아이가 층을 망가뜨렸을 때 `build.js` 의 `reset` 을 쓴다.

1. `buildFloor` 변수를 되돌릴 층 번호로 바꾼다
2. 채팅창에 `reset` 입력

그 층만 처음 상태로 돌아간다. 조명도 다시 깔린다. **다른 층은 건드리지 않는다.**

수업 중 여러 명이 같은 월드에 있다면 복구가 모두에게 적용된다는 점을 주의한다.

---

## 7. 배포와 백업

건설이 끝나면 **월드를 내보내(`.mcworld`) 백업**한다. 매 기수 이 파일을 복제해서 쓴다.

```
설정 → 월드 내보내기 → signal-12_원본.mcworld
```

아이용 배포본은 게임 모드를 **서바이벌**로 바꾼 뒤 다시 내보낸다. 크리에이티브면 아이가 날아다니며 층을 건너뛴다.

## 8. 블록 이름을 바꿔야 할 때

`build.js` 에 쓴 블록 상수는 MakeCode 버전에 따라 이름이 다를 수 있다.
블록 팔레트에서 원하는 블록을 찾아 JS 탭에서 이름을 확인한 뒤 교체한다.

| 쓰인 상수 | 용도 | 바꿔도 되는 것 |
|---|---|---|
| `STONE` | 층 외벽 | `DEEPSLATE` `STONE_BRICKS` |
| `AIR` | 공간 비우기 | 바꾸지 않는다 |
| `GLOWSTONE` | 조명 | `SEA_LANTERN` `SHROOMLIGHT` |
| `COBBLESTONE` | 7층 붕괴 잔해 | `GRAVEL` `ANDESITE` |
| `WATER` | 8층 침수 | 바꾸지 않는다 |
| `IRON_BLOCK` | 12층 신호원 단상 | `NETHERITE_BLOCK` `COPPER_BLOCK` |

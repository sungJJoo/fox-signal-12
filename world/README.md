# 월드 구성 안내

「에이전트와 함께해요 2 — 지하 12층」 전용 월드를 만드는 절차다. 한 번 만들어두고 매 기수 복제해서 쓴다.

---

## 1. 월드 생성 설정

| 항목 | 값 |
|---|---|
| 월드 이름 | `signal-12` |
| 게임 모드 | **크리에이티브** (건설 시) → 수업 중에는 **서바이벌** |
| 난이도 | 평화로움 |
| 좌표 보기 | **켜기** (필수. 이 프로그램 전체가 좌표로 돌아간다) |
| 시간 | 항상 낮 |
| 날씨 변화 | 끄기 |
| 즉시 존중 | 켜기 |
| 시드 | 지정하지 않는다 |

**좌표 보기를 반드시 켠다.** 1차시 활동 전체가 화면 좌표를 읽는 것이다.

**평화로움**으로 두는 이유는 지하가 어두워 몹이 계속 나오기 때문이다. 6층은 일부러 조명이 없다.

---

## 2. 지상 관제실 위치 정하기

월드에 들어가서 평평한 곳을 찾은 뒤, `/tp` 로 **X = -12, Z = 8** 근처로 이동한다.

```
/tp -12 ~ 8
```

여기가 갱도 입구다. 지상 Y가 얼마인지 화면에서 확인해둔다. 보통 63~70 사이다.
지형이 이 좌표에서 산이나 바다면 다른 곳에 월드를 새로 만드는 편이 빠르다.

---

## 3. 건설 코드 실행

`world/build.js` 를 **별도의 MakeCode 프로젝트**에 붙여넣는다. 수업용 프로젝트와 섞지 않는다.

채팅창(`T`)에서 순서대로 실행한다.

```
buildall
```
지하 1~12층과 수직 갱도를 한 번에 만든다. 관제 홀·층 번호 표시·조명·외곽 배관·신호 표식·층별 시설까지 전부 포함이다. **4~6분** 걸리고 그동안 화면이 버벅인다. 정상이다.

렉이 너무 심하면 `buildall` 대신 `buildone` 을 쓴다. `buildFloor` 변수를 1부터 12까지 바꿔가며 열두 번 실행하고, 마지막에 `shaft` 를 한 번 실행한다.

```
check
```
1층부터 12층까지 갱도를 순서대로 훑는다. 층당 1.2초, 총 15초.

```
checksig
```
12개 신호 지점을 순서대로 훑는다. **표식 한가운데에 정확히 서는지** 확인하는 용도다. 벽에 박히면 그 층 좌표가 틀린 것이다.

## 4. 만들어지는 구조

```
지상  Y 63~79   갱도 (3x3 수직 통로)
─────────────────────────────
1층   Y 58      절대 좌표
2층   Y 54      채팅 매개변수
3층   Y 50      매개변수 여러 개
4층   Y 46      변수
5층   Y 42      층 계산기
6층   Y 38      조명 없음  ← 일부러 어둡다
7층   Y 34      통로 붕괴  ← 조약돌 장애물 (count 가 셀 대상)
8층   Y 30      침수      ← 바닥 걷어내고 물 (raft 가 채울 자리)
9층   Y 26      바닥 붕괴  ← 바닥 걷어냄 (deck9 자리)
10층  Y 22      갈림길
11층  Y 18      전층 스캔
12층  Y 14      신호원    ← 조약돌 통로 + 철블록 단상 + 발광석
```

각 층 홀 크기는 **X -30~2, Y 3칸, Z -14~24** 다.
층과 층 사이는 돌 한 겹으로 막혀 있고, 갱도만 세로로 관통한다.

### 층마다 공통으로 들어가는 것

| 구역 | 위치 | 설명 |
|---|---|---|
| 관제 홀 | X -16~-8, Z 4~12 | 갱도를 감싼 방. 바닥이 다른 재질이다 |
| 출입구 | (-16,8) (-8,8) (-12,4) (-12,12) | 사방에 하나씩. **다른 곳은 벽이다** |
| 관제 콘솔 | 홀 안 Z=6, Z=10 | 석영 + 레드스톤. 미션 동선(Z=8)을 피해 놓았다 |
| 층 번호 점 | Z=14, X -17부터 | 발광석을 층 수만큼. **세어보면 몇 층인지 안다** |
| 천장 조명 | 8칸 격자 | 6층만 없다 |
| 외곽 배관 | 테두리 | 철창살. 방이 아니라 시설로 보이게 하는 장식 |
| 갱도 유도등 | X=-14, Z=8 | 층마다 하나. 내려가는 동안 층이 지나가는 게 보인다 |
| 신호 표식 | 층별 | 강철 3×3 단상 + 가운데 붉은 코어 + 네 귀퉁이 기둥 |

**신호 표식의 가운데 칸은 비어 있다.** 거기로 에이전트를 투입하기 때문이다.
표식을 손볼 때 이 규칙을 깨면 `sig` 명령들이 전부 벽에 박힌다.

### 층별로 다른 것

| 층 | 시설 |
|---|---|
| 6 | 조명 없음. 유도등을 직접 심어야 한다 |
| 7 | Z=20 통로에 잔해 4군데 + 양옆 무너진 벽. `count 12` 가 셀 대상이다 |
| 8 | X -10~-2, Z -8~2 바닥을 걷어내고 물. 가장자리를 다른 바닥재로 표시 |
| 9 | X -30~-20, Z 2~12 바닥 붕괴. **신호 지점만 섬으로 남는다** |
| 10 | 칸막이 벽으로 갈림길. Z=8 통로와 X=0 통로만 열려 있다 |
| 11 | 신호 증폭기 — 신호 지점을 벽 두 개가 감싼다 |
| 12 | 갱도에서 서쪽으로 무너진 통로 + 봉인 격납고와 단상 |

## 5. 에이전트 슬롯 준비

차시마다 필요한 재료가 다르다. **수업 시작 전에 미리 넣어둔다.**
에이전트를 우클릭하면 인벤토리가 열린다.

| 차시 | 슬롯 1 | 슬롯 2 | 비고 |
|---|---|---|---|
| 1~2 | — | — | 재료 필요 없음 |
| 3 | **석재 64** | — | `deck` `tower` |
| 4 | 석재 64 | **색 블록 64** | `mark` `ring` 표식 |
| 5 | 석재 64 | 색 블록 64 | `build` |
| 6 | **글로우스톤 64** | — | 유도등 |
| 7 | 글로우스톤 64 | — | 6차시 유지 |
| 8 | **석재 64** | — | `raft` 는 최대 64칸까지 |
| 9 | 석재 64 | — | `deck9` |
| 10 | 석재 64 | **색 블록 64** | `roadx` 는 석재, `tag` 는 색 블록 |
| 11 | **글로우스톤 64** | — | `relight` 는 층당 3개 |
| 12 | **석재 64** | **글로우스톤 64** | 착륙장 25칸 + 유도등 4개 |

색 블록은 어두운 지하에서도 확 눈에 띄는 것을 고른다. 노란색·빨간색 계열이 좋다.

**8차시 주의** — `raft 8 10` 은 블록 80개가 필요한데 한 슬롯에는 64개까지만 들어간다.
이건 버그가 아니라 학습 장치다. `need` 명령으로 미리 계산해 부족을 발견하게 되어 있다.
슬롯 1을 64개로만 채워둔다.

## 6. 수업 중 복구

아이가 층을 망가뜨렸을 때 `build.js` 의 `reset` 을 쓴다.

1. `buildFloor` 변수를 되돌릴 층 번호로 바꾼다
2. 채팅창에 `reset` 입력

그 층만 처음 상태로 돌아간다. 조명도 다시 깔린다. **다른 층은 건드리지 않는다.**

수업 중 여러 명이 같은 월드에 있다면 복구가 모두에게 적용된다는 점을 주의한다.

## 7. 배포와 백업

건설이 끝나면 **월드를 내보내(`.mcworld`) 백업**한다. 매 기수 이 파일을 복제해서 쓴다.

```
설정 → 월드 내보내기 → signal-12_원본.mcworld
```

아이용 배포본은 게임 모드를 **서바이벌**로 바꾼 뒤 다시 내보낸다. 크리에이티브면 아이가 날아다니며 층을 건너뛴다.

## 8. 블록 이름을 바꿔야 할 때

`build.js` 에 쓴 블록 상수는 MakeCode 버전에 따라 이름이 다를 수 있다.
블록 팔레트에서 원하는 블록을 찾아 JS 탭에서 이름을 확인한 뒤 교체한다.

**"Cannot find name 'XXX'" 오류가 나면** 이렇게 찾는다.

1. Blocks 탭으로 간다
2. 왼쪽 **블록** 카테고리에서 원하는 블록을 아무 데나 하나 끌어다 놓는다
3. JavaScript 탭으로 바꾼다
4. 거기 적힌 이름을 복사해서 `build.js` 맨 위 목록에 붙인다
5. 2번에서 끌어다 놓은 블록은 지운다

**실기에서 확인된 것 (2026-08)** — `QUARTZ_BLOCK` 은 MakeCode 에 없는 이름이다. `MAT_CONSOLE` 은 `IRON_BLOCK` 으로 바꿔뒀다.
나머지 9개(`STONE` `STONE_BRICKS` `POLISHED_ANDESITE` `GLOWSTONE` `COBBLESTONE` `GRAVEL` `IRON_BLOCK` `REDSTONE_BLOCK` `IRON_BARS`)는 통과했다.

| 쓰인 상수 | 용도 | 바꿔도 되는 것 |
|---|---|---|
| `STONE` | 층 외벽 | `DEEPSLATE` `STONE_BRICKS` |
| `AIR` | 공간 비우기 | 바꾸지 않는다 |
| `GLOWSTONE` | 조명 | `SEA_LANTERN` `SHROOMLIGHT` |
| `COBBLESTONE` | 7층 붕괴 잔해 | `GRAVEL` `ANDESITE` |
| `WATER` | 8층 침수 | 바꾸지 않는다 |
| `IRON_BLOCK` | 신호 단상 · 관제 콘솔 | `NETHERITE_BLOCK` `COPPER_BLOCK` |

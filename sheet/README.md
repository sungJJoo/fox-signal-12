# 구글 시트 백업 — 설치와 운영

아이가 웹 교재에 쓴 답을 구글 시트에 자동으로 쌓는다. 두 가지를 해결한다.

- 노트북이 바뀌거나 브라우저 기록이 지워져도 **이름만 넣으면 기록이 돌아온다**
- 연구원이 **시트 하나로 전체 아이의 진도와 답변을 본다**

**이 설정을 안 해도 수업은 정상적으로 돌아간다.** `config.js` 를 비워두면 웹 교재는 브라우저에만 저장한다. 노트북이 아이별로 고정이라면 그것만으로도 12주가 유지된다. 시트 연동은 안전망이자 연구원용 도구다.

---

## 1. 시트 만들고 스크립트 붙이기

1. 구글 드라이브에서 새 스프레드시트를 만든다. 이름은 `signal12_기록` 정도로.
2. 상단 메뉴 **확장 프로그램 → Apps Script**
3. 기본으로 있는 `Code.gs` 내용을 전부 지우고, 이 폴더의 `Code.gs` 를 통째로 붙여넣는다.
4. 저장 (`Ctrl+S`)

---

## 2. 토큰 정하기 (권장)

`Code.gs` 맨 위를 고친다.

```js
var TOKEN = "fox2026";
```

아무 문자열이나 된다. 나중에 웹 교재 쪽에도 **똑같이** 넣는다.

> 이건 진짜 보안 장치가 아니다. 웹 교재는 공개 페이지라 토큰이 소스에 그대로 보인다.
> 주소를 우연히 알게 된 사람이 장난치는 걸 막는 정도다.
> 실명이 신경 쓰이면 아이에게 **번호나 별명**을 쓰게 하면 된다. 웹 교재는 무엇을 넣든 받는다.

---

## 3. 웹앱으로 배포

1. Apps Script 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴 → **웹 앱** 선택
3. 설정

| 항목 | 값 |
|---|---|
| 설명 | `signal12` |
| 다음 사용자로 실행 | **나** |
| 액세스 권한 | **모든 사용자** |

4. **배포** 를 누르면 권한 승인을 요구한다. 승인한다.
   "이 앱은 확인되지 않았습니다" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동** 을 누른다. 본인이 만든 스크립트라 정상이다.
5. 나온 **웹 앱 URL** 을 복사한다. `.../exec` 로 끝난다.

**액세스 권한을 "모든 사용자"로 해야 한다.** 아이들이 구글 로그인 없이 접속하기 때문이다.

---

## 4. 웹 교재에 주소 넣기

저장소의 `docs/data/config.js` 를 고친다.

```js
window.SIGNAL12_CONFIG = {
  SHEET_URL: "https://script.google.com/macros/s/AKfy.../exec",
  TOKEN: "fox2026"
};
```

`TOKEN` 은 3단계에서 `Code.gs` 에 넣은 값과 **똑같아야** 한다.

고쳤으면 commit + push 한다. 1~2분 뒤 사이트에 반영된다.

```bash
git add docs/data/config.js && git commit -m "구글 시트 백업 주소 연결" && git push
```

---

## 5. 동작 확인

1. 사이트를 열고 이름을 넣는다
2. 아무 층에 들어가 관찰 기록에 한 줄 쓴다
3. 이름 막대 오른쪽이 **"시트 저장됨"** 으로 바뀌는지 본다
4. 구글 시트에 `기록` 탭이 생기고 한 줄이 들어왔는지 본다
5. **다른 브라우저(시크릿 창)** 로 사이트를 열고 같은 이름을 넣는다 → 아까 쓴 내용이 딸려오면 성공

`시트 연결 안 됨` 이 뜨면 아래 문제 해결을 본다.

---

## 6. 시트 구조

### `기록` 탭 — 자동 생성

| 이름 | 항목키 | 층 | 질문 | 답변 | 수정시각 |
|---|---|---|---|---|---|
| 박서준 | f5:o2 | 5 | 1층부터 12층까지 Y를 계산해서 적어봐 | 58 54 50... | 2026-09-02 16:41 |

같은 아이의 같은 항목은 **덮어쓴다.** 행이 무한정 늘지 않는다.
상단 필터를 걸면 아이별·층별로 바로 추려볼 수 있다.

### `진도` 탭 — 메뉴에서 생성

시트 상단 메뉴 **AI 연구소 → 진도표 새로 만들기** 를 누르면 만들어진다.

| 이름 | 1층 | 2층 | 3층 | ... | 합계 |
|---|---|---|---|---|---|
| 박서준 | 5 | 5 | 4 | | 14 |
| 김하늘 | 5 | 3 | | | 8 |

칸 안 숫자는 그 층에서 답을 쓴 항목 수다. **빈 칸이 이어지는 아이가 멈춘 아이다.**
매 차시 끝나고 한 번 눌러보면 누구를 봐야 할지 바로 나온다.

메뉴가 안 보이면 시트를 새로고침한다. `onOpen` 은 시트를 열 때 등록된다.

---

## 7. 문제 해결

| 증상 | 원인 | 대응 |
|---|---|---|
| 계속 "시트 연결 안 됨" | 배포 액세스 권한이 "모든 사용자"가 아니다 | 배포 설정을 다시 확인 |
| 같은 증상 | `SHEET_URL` 이 `/dev` 로 끝난다 | `/exec` 주소를 써야 한다 |
| 같은 증상 | 토큰이 양쪽에서 다르다 | `Code.gs` 와 `config.js` 를 대조 |
| 저장은 되는데 불러오기가 안 된다 | 이름이 미묘하게 다르다 | 시트 `기록` 탭에서 이름 표기 확인. 공백도 다른 이름이다 |
| 코드를 고쳤는데 반영이 안 된다 | 배포를 갱신 안 했다 | **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** |
| 학교 네트워크에서 안 된다 | `script.google.com` 이 차단됐다 | 브라우저 저장만으로 운영. `config.js` 를 비운다 |
| 기록이 다른 아이 것과 섞였다 | 두 아이가 같은 이름을 썼다 | 이름 뒤에 번호를 붙이게 한다 (`박서준2`) |

---

## 8. 운영 시 주의

- **첫 주에 이름 표기를 통일한다.** 「박서준」과 「서준」은 다른 사람으로 저장된다. 첫 차시에 칠판에 적어두고 그대로 쓰게 한다.
- 기록은 아이가 글자를 칠 때마다 저장되는 게 아니라 **1.5초 쉬면** 저장된다. 다 쓰자마자 노트북을 덮으면 마지막 한 줄이 안 갈 수 있다.
- 시트에는 아이 **이름과 답변**이 들어간다. 다른 개인정보는 저장하지 않는다. 기수가 끝나면 시트를 따로 보관하거나 이름을 번호로 바꿔 정리한다.
- 시트를 실수로 지우면 아이 브라우저에는 기록이 남아 있다. 12차시 **내 기록 전부 내보내기** 로 각자 파일을 뽑게 하면 이중 백업이 된다.

기록은 브라우저에 저장된다

각 층에서 적은 관찰 기록과 계산은 이 브라우저에 자동으로 저장된다. 다음 주에 같은 노트북으로 들어오면 그대로 남아 있다. 마지막 층에서 전부 내보내기를 누르면 열두 주치 기록이 파일 하나로 나온다.

주의 다른 노트북을 쓰거나 브라우저 기록을 지우면 저장한 내용이 사라져. 매 차시 끝나고 화면 캡처도 같이 남겨두는 게 안전해.

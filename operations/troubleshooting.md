## 코드가 실행되지 않는다

| 증상 | 원인 순서 | 확인 방법 |
|---|---|---|
| 채팅에 명령을 쳐도 무반응 | ① 저장 안 함 ② 철자 다름 ③ 다른 프로젝트를 열어둠 | 코드의 `onChat` 안 문자열과 채팅 입력을 한 글자씩 대조 |
| 명령 절반만 실행됨 | `loops.pause` 누락 | 각 동작 뒤에 300 이상 넣는다 |
| 실행은 되는데 아무 변화 없음 | 에이전트가 화면 밖에 있음 | `mark` 또는 `home` 으로 불러온다 |
| MakeCode가 안 열림 | `C` 키 매핑 문제 | 채팅창에 `/code` |

## 에이전트 관련

| 증상 | 원인 | 대응 |
|---|---|---|
| 에이전트가 안 보인다 | 아직 스폰 안 됨 | `mark` (1차시 명령) |
| 블록 속에 끼었다 | 좌표를 벽 안으로 지정 | `home` 으로 복귀. 3차시 전이라면 `mark` |
| 블록을 안 놓는다 | ① 슬롯이 비었다 ② 놓을 자리가 차 있다 | 에이전트 우클릭 → 인벤토리 확인 → `destroy` 를 앞에 붙인다 |
| 부순 아이템이 안 들어온다 | `collectAll` 누락 또는 위치가 `destroy` 앞 | `destroy` 뒤에 넣는다 |
| 이동 명령이 무시된다 | 앞이 막혔다 | `detect` 로 확인하거나 `destroy` 먼저 |
| 슬롯을 바꿔도 같은 블록이 나온다 | `setSlot` 이 반복 밖에 한 번만 있다 | 반복 안으로 옮긴다 |

## 좌표 관련

| 증상 | 원인 | 대응 |
|---|---|---|
| 화면에 좌표가 안 보인다 | 좌표 보기 꺼짐 | 설정 → 게임 → 좌표 보기. **클라이언트마다** 확인 |
| 엉뚱한 곳으로 간다 | `world` 대신 `pos` 를 씀 | 전부 `world` 로 통일 |
| 반대편으로 간다 | 마이너스 부호 누락 | `-12` 를 `12` 로 친 것. 부호 확인 |
| Y가 음수로 나온다 | 층 번호가 15를 넘음 | 층은 1~12까지만 |
| 계산 결과가 틀리다 | 연산 순서 오류 | `62 - (층 × 4)`. 곱하기가 빼기 **안**에 들어가야 한다 |
| 층 사이를 못 지나간다 | 갱도 밖에서 이동 중 | 갱도는 X -12, Z 8 이다. 그 밖은 층 사이가 막혀 있다 |

## 월드 관련

| 증상 | 원인 | 대응 |
|---|---|---|
| 층이 안 만들어졌다 | `buildall` 이 중간에 끊김 | `buildFloor` 를 그 층으로 두고 `buildone` |
| 층이 물에 잠겼다 | 지형의 지하수가 유입 | 해당 층에 `reset` 실행 |
| 층 홀에 용암이 있다 | 돌 껍질보다 용암이 먼저 | `reset` 실행. 반복되면 월드를 다른 좌표에 새로 만든다 |
| 갱도가 중간에 막혔다 | 갱도 AIR fill 누락 | `buildall` 의 마지막 두 줄만 다시 실행 |
| 6층이 안 어둡다 | `props` 의 `if (f != 6)` 조건이 빠졌다 | 6층에서 발광석을 수동으로 걷어낸다 |
| 아이가 층을 망가뜨렸다 | — | `buildFloor` 설정 후 `reset` |
| 몹이 계속 나온다 | 난이도가 평화로움이 아니다 | 월드 설정 → 난이도 → 평화로움 |
| 빌드 중 게임이 멈춘다 | fill 범위가 커서 렉 | `buildall` 대신 `buildone` 을 12번 |

## MakeCode 블록 변환

붙여넣은 코드가 **회색 JavaScript 블록**으로 나올 때다.

| 회색으로 나온 부분 | 원인 문법 | 교체 |
|---|---|---|
| 변수 선언 | `const` | `let` |
| 명령 전체 | `() => { }` | `function () { }` |
| 반복 | `while` | `for (let i = 0; i < n; i++)` |
| 메시지 | `` `${변수}` `` | `player.say(변수)` |
| 조건 여러 개 | `switch` | `if / else` |
| 목록 | `[1, 2, 3]` | 이번 프로그램에서는 쓰지 않는다 |

전체 목록은 `code/README.md` 에 있다.

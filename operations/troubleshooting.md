## 코드가 실행되지 않는다

| 증상 | 원인 순서 | 확인 방법 |
|---|---|---|
| 채팅에 명령을 쳐도 무반응 | ① 저장 안 함 ② 철자 다름 ③ 다른 프로젝트를 열어둠 | 코드의 `onChat` 안 문자열과 채팅 입력을 한 글자씩 대조 |
| **숫자를 쳤는데 안 먹음** | **띄어쓰기 누락** | `dive3` ✗ / `dive 3` ✓. 숫자 사이도 한 칸씩 |
| 숫자를 줬는데 항상 1만 동작 | 방어 장치가 `if (x < 1)` 이 아니라 무조건 대입 | `if` 조건 안을 확인 |
| 숫자를 안 줬는데 뭔가 동작함 | 정상. 방어 장치가 1로 바꿔준 것 | 2차시에서 일부러 만든 동작이다 |
| 명령 절반만 실행됨 | `loops.pause` 누락 | 각 동작 뒤에 200~300 넣는다 |
| 실행은 되는데 아무 변화 없음 | 에이전트가 화면 밖(지하)에 있음 | `back`(1~3차시) 또는 `home`(4차시~) |
| MakeCode가 안 열림 | `C` 키 매핑 문제 | 채팅창에 `/code` |

## 좌표 관련

| 증상 | 원인 | 대응 |
|---|---|---|
| 화면에 좌표가 안 보인다 | 좌표 보기 꺼짐 | 설정 → 게임 → 좌표 보기. **클라이언트마다** 확인 |
| 엉뚱한 곳으로 간다 | `world` 대신 `pos` 를 씀 | 전부 `world` 로 통일 |
| 반대편으로 간다 | 마이너스 부호 누락 | `-12` 를 `12` 로 친 것. 부호 확인 |
| Y가 음수로 나온다 | 층 번호가 15를 넘음 | 층은 1~12까지만 |
| 계산 결과가 틀리다 | 연산 순서 오류 | `62 - (층 × 4)`. 곱하기가 빼기 **안**에 들어가야 한다 |
| 층 사이를 못 지나간다 | 갱도 밖에서 이동 중 | 갱도는 X -12, Z 8 이다. 그 밖은 층 사이가 막혀 있다 |

## 월드 관련

| 증상 | 원인 | 대응 |
|---|---|---|
| 층이 안 만들어졌다 | `buildall` 이 중간에 끊김 | `buildFloor` 를 그 층으로 두고 `buildone` |
| 층이 물에 잠겼다 | 지형의 지하수가 유입 | 해당 층에 `reset` 실행 |
| 층 홀에 용암이 있다 | 돌 껍질보다 용암이 먼저 | `reset` 실행. 반복되면 월드를 다른 좌표에 새로 만든다 |
| 갱도가 중간에 막혔다 | 갱도 AIR fill 누락 | `buildall` 의 마지막 두 줄만 다시 실행 |
| 6층이 안 어둡다 | `props` 의 `if (f != 6)` 조건이 빠졌다 | 6층에서 발광석을 수동으로 걷어낸다 |
| 아이가 층을 망가뜨렸다 | — | `buildFloor` 설정 후 `reset` |
| 몹이 계속 나온다 | 난이도가 평화로움이 아니다 | 월드 설정 → 난이도 → 평화로움 |
| 빌드 중 게임이 멈춘다 | fill 범위가 커서 렉 | `buildall` 대신 `buildone` 을 12번 |

## MakeCode 블록 변환

붙여넣은 코드가 **회색 JavaScript 블록**으로 나올 때다.

| 회색으로 나온 부분 | 원인 문법 | 교체 |
|---|---|---|
| 변수 선언 | `const` | `let` |
| 명령 전체 | `() => { }` | `function () { }` |
| 반복 | `while` | `for (let i = 0; i < n; i++)` |
| 메시지 | `` `${변수}` `` | `player.say(변수)` |
| 조건 여러 개 | `switch` | `if / else` |
| 부정 조건 | `!조건` | `if / else` 로 뒤집는다 |
| 목록 | `[1, 2, 3]` | 이번 프로그램에서는 쓰지 않는다 |
| 채팅 매개변수 | 이름을 바꿔 씀 | `num1` `num2` `num3` 그대로 |

전체 목록은 `code/README.md` 에 있다.

**매개변수 이름은 절대 바꾸지 않는다.** MakeCode가 블록에서 생성하는 이름이 `num1` `num2` `num3` 이라, 다른 이름을 쓰면 왕복 변환이 어긋날 수 있다. 뜻이 필요하면 명령 안에서 지역 변수로 옮겨 담는다.

## 기록 저장

| 증상 | 원인 | 대응 |
|---|---|---|
| 입력칸이 회색이고 안 써진다 | 이름을 안 넣었다 | 페이지 위 이름 칸에 넣는다. 안 넣으면 저장할 곳이 없다 |
| 지난주 기록이 없다 | 이름을 다르게 썼다 | 「박서준」과 「서준」은 다른 사람이다. **첫 차시에 표기를 통일해둘 것** |
| 같은 증상 | 다른 노트북에 앉았다 | 시트를 연결했으면 이름만 넣으면 온다. 안 했으면 복구 불가 |
| 기록이 남의 것과 섞였다 | 두 아이가 같은 이름을 썼다 | 이름 뒤에 번호를 붙인다 (`박서준2`) |
| "시트 연결 안 됨" 이 뜬다 | 네트워크 또는 배포 문제 | **기록 자체는 브라우저에 안전하다.** 수업은 그대로 진행. `sheet/README.md` 7장 참고 |
| 마지막에 쓴 한 줄이 시트에 없다 | 쓰자마자 창을 닫았다 | 시트 저장은 1.5초 쉰 뒤에 나간다. 다 쓰고 잠깐 두고 닫게 한다 |
| 브라우저 기록을 지웠다 | localStorage 삭제 | 시트를 연결했으면 이름으로 복원. 안 했으면 복구 불가 |

## MCP 를 붙였을 때

| 증상 | 원인 | 대응 |
|---|---|---|
| 채팅 명령이 전부 무응답 | `/connect` 로 MakeCode 연결이 끊겼다 | 월드를 나갔다 들어오거나 `C` 키로 Code Builder 재시작 |
| `서버가 닫혔습니다` | 같은 원인 | 위와 같다 |
| 수업 중 아이들 코드가 멈췄다 | 누가 `/connect` 를 쳤다 | **수업 중에는 MCP 를 쓰지 않는다** |
| MCP 도구가 `not available` | 게임이 MakeCode 쪽에 붙어 있다 | 검사할 때만 `/connect` 를 다시 친다 |

**MakeCode 와 MCP 는 동시에 못 쓴다.** 자세한 내용은 `world-verify.md` 참고.

## 그래도 안 될 때

1. `context-notes.md` 3장에서 좌표 기준값을 다시 확인한다
2. `world/build.js` 의 `check` 명령으로 12층을 훑어 월드 상태를 눈으로 본다
3. `code/all-floors.js` 를 새 프로젝트에 붙여넣어 코드 쪽 문제인지 월드 쪽 문제인지 가른다
